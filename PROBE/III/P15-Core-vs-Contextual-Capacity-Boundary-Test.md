# P15 — Core Capacity vs Contextual Capacity Boundary Test

## Working definition
**Core Capacity** = functional developmental construct dengan identity cukup stabil untuk dikembangkan dan dimobilisasi pada lebih dari satu context, walaupun manifestation dapat berbeda.

## Boundary principles
1. Context ≠ Capacity.
2. Behavior ≠ Capacity.
3. Skill ≠ Core Capacity.
4. Competency ≠ Core Capacity.
5. Value ≠ Capacity.
6. Character ≠ Capacity.
7. Capacity dapat dimobilisasi dalam competency/performance.
8. Capacity dapat memiliki contextual manifestations.
9. Religious practice tidak direduksi menjadi generic Capacity.
10. Ontological status ditentukan definition/function, bukan nama.

Contoh: public speaking lebih mungkin skill/contextual competency di bawah Communication; boarding adaptation tidak otomatis Capacity; critical thinking dalam kajian kitab tetap dapat menjadi manifestation Critical Thinking.

## Keputusan
**PASS — STRONG.**
