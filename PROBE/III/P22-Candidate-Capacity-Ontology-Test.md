# P22 — Candidate Capacity Ontology Test

## Candidate review
- Learning: ambiguous process/change/outcome/ability → **HOLD**.
- Decision Making: outcome ≠ decision-making ability → **CONDITIONAL**.
- Agency: integrative and opportunity-dependent → **STRONG CANDIDATE**, belum final.
- Adaptability: candidate Capacity; redundancy dengan resilience/self-regulation belum selesai → **VALID CANDIDATE**.
- Resilience: broad/overlapping → **HOLD**.
- Empathy: broad/ambiguous → **HOLD**.
- Social Understanding: functional candidate, overlap unresolved → **HOLD/CONDITIONAL**.
- Physical Functioning: valid candidate; dibedakan dari health, fitness, sport skill, self-care → **VALID**.
- Self-Care: mixed behavior/habit/routine/capacity → **HOLD**.

Spiritual Capacity generic tidak dibuat karena risiko psychologizing faith/ibadah. Religious practice tidak direduksi menjadi generic psychometric score.

## Stronger pool
Self-Regulation, Critical Thinking, Problem Solving, Communication, Collaboration, Physical Functioning, Adaptability.

## Keputusan
**PASS — MAJOR ONTOLOGICAL CLEANUP.** Important ≠ Capacity.
