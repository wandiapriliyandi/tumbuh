# P18 — Candidate Capacity Ontology Test

## Candidate review
- Learning: ambiguous process/change/outcome/ability → HOLD.
- Decision Making: outcome ≠ ability → CONDITIONAL.
- Agency: integrative and opportunity-dependent → STRONG CANDIDATE, not final.
- Adaptability: candidate Capacity; redundancy unresolved → VALID CANDIDATE.
- Resilience: broad overlap → HOLD.
- Empathy: broad/ambiguous → HOLD.
- Social Understanding: functional candidate; overlap unresolved → HOLD/CONDITIONAL.
- Physical Functioning: valid candidate; distinguish health, fitness, sport skill, self-care → VALID.
- Self-Care: mixed behavior/habit/routine/capacity → HOLD.

Spiritual Capacity generic ditolak sementara karena risiko psychologizing faith/ibadah. Religious practice tidak direduksi menjadi generic psychometric score.

## Stronger pool
Self-Regulation, Critical Thinking, Problem Solving, Communication, Collaboration, Physical Functioning, Adaptability.

## Keputusan
**PASS — MAJOR ONTOLOGICAL CLEANUP.** Important ≠ Capacity.
