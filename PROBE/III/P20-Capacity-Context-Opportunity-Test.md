# P20 — Capacity × Context × Opportunity Test

## Temuan
Model Person → Capacity → Performance terlalu sederhana. Person-in-context lebih sesuai:

```text
Capacity + Context + Opportunity + Support
↓
Functioning
↓
Performance / Behavior
↓
Evidence
```

Capacity ≠ opportunity to express capacity. Good performance dapat berasal dari internal capacity, external structure, atau keduanya.

Supported functioning legitimate; autonomy tidak identik dengan absence of support.
