# P0073 — Core Capacity–Knowledge, Skill, Learning, and Capacity Change Boundary Audit

## Status

**PASS — DENGAN GUARDRAIL**

## Purpose

Probe ini menguji batas ontologis dan fungsional antara Knowledge, Skill, Learning, Practice, Mastery, Performance, Capacity, Capacity Change, dan Growth.

Fokus utamanya adalah mencegah penyederhanaan:

> **Sudah belajar = capacity sudah berkembang.**

## Core Principle

> **Knowledge, skill, learning, dan mastery dapat menjadi resources, processes, atau manifestations yang berhubungan dengan development; semuanya tidak otomatis merupakan Core Capacity atau bukti Capacity Change.**

## 1. Knowledge ≠ Capacity

Knowledge adalah apa yang diketahui/dipahami seseorang mengenai suatu content atau domain.

Knowledge dapat mendukung functioning, tetapi kepemilikan knowledge tidak otomatis menunjukkan capacity tertentu.

```text
Knowledge ↑
   ≠
Capacity ↑
```

Contoh: mengetahui langkah problem solving tidak otomatis membuktikan Problem Solving capacity dalam situasi nyata.

## 2. Skill ≠ Capacity

Skill adalah kemampuan melakukan tindakan/prosedur tertentu secara terlatih.

Skill dapat menjadi resource atau manifestation bagi capacity tertentu, tetapi tidak identik dengan capacity.

```text
Skill ↑
   ≠
Capacity ↑
```

Satu skill dapat mendukung beberapa capacities, dan satu capacity dapat membutuhkan banyak skills.

## 3. Learning ≠ Capacity Change

Learning memiliki penggunaan konseptual yang luas dan dapat menunjuk pada perubahan knowledge, skill, understanding, strategy, atau functioning.

Karena itu:

```text
Learning
   ≠ automatically
Capacity Change
```

Learning dapat menjadi salah satu proses yang berkontribusi pada Capacity Change, tetapi hubungan tersebut tidak boleh diasumsikan sebagai identitas atau causal law universal.

## 4. Practice ≠ Learning

Practice adalah keterlibatan berulang atau terarah dalam aktivitas tertentu.

Practice dapat mendukung learning, tetapi practice tanpa meaningful engagement atau adaptation tidak otomatis menghasilkan learning.

```text
Practice
   ≠
Learning
```

## 5. Practice ≠ Capacity Change

Temuan P0069 tetap berlaku.

Repetition, frequency, duration, dan dose bukan direct proxy untuk Capacity Change.

```text
Practice ↑
   ≠
Capacity Change ↑
```

## 6. Mastery ≠ Capacity

Mastery adalah tingkat penguasaan terhadap suatu task, skill, content, atau domain tertentu.

Mastery dapat menjadi evidence yang relevan, tetapi tidak otomatis identik dengan Core Capacity.

```text
Mastery of Task
   ≠
Core Capacity
```

Task mastery juga dapat meningkat karena familiarity tanpa broad developmental change.

## 7. Performance ≠ Capacity

Temuan P0044, P0045, P0053, dan P0070 tetap berlaku.

Performance adalah apa yang terjadi dalam task/context tertentu.

Capacity adalah construct developmental-functional yang menjadi target inference.

```text
Performance
   ≠
Capacity
```

## 8. Capacity Change

Capacity Change adalah perubahan pada state/functioning capacity dari waktu ke waktu yang cukup didukung evidence dan contextual interpretation.

Perubahan score, task success, atau performance saja belum cukup untuk menyimpulkan Capacity Change.

## 9. Growth ≠ Learning

Growth dalam TUMBUH memiliki arah normative melalui Graduate Profile dan worldview.

Learning dapat terjadi tanpa perubahan yang cukup berarti terhadap arah growth yang dituju.

```text
Learning
   ≠
Growth
```

Growth juga tidak boleh direduksi menjadi accumulation of knowledge.

## 10. Knowledge as Resource

Knowledge dapat berfungsi sebagai resource yang memungkinkan capacity berfungsi lebih efektif.

```text
Capacity
   ↕
Knowledge / Resources
   ↓
Functioning
```

Namun resource ≠ construct.

## 11. Skill as Resource or Manifestation

Skill dapat berperan sebagai:

- resource untuk functioning;
- cara spesifik menjalankan suatu fungsi;
- manifestation yang menyediakan evidence;
- target pembelajaran tersendiri.

Klasifikasi bergantung pada intended inference.

## 12. One Skill, Multiple Capacities

Satu skill tidak otomatis memiliki satu pemilik capacity.

Misalnya kemampuan menyampaikan argumen dapat melibatkan:

- Communication;
- Critical Thinking;
- Self-Regulation;
- Social Understanding.

Karena itu skill tidak boleh dipetakan satu-to-one secara kaku ke Core Capacity.

## 13. One Capacity, Multiple Skills

Sebaliknya, satu Core Capacity dapat dimanifestasikan melalui banyak skill.

Problem Solving dapat melibatkan berbagai skill yang berbeda menurut problem dan konteks.

Maka:

```text
Skill ↔ Capacity
```

lebih tepat daripada:

```text
1 Skill = 1 Capacity
```

## 14. Learning as Process / Change / Outcome Ambiguity

Istilah Learning harus dijaga karena dapat digunakan untuk menunjuk:

- proses belajar;
- perubahan akibat belajar;
- hasil belajar;
- kemampuan untuk belajar, dalam penggunaan tertentu.

Karena ambiguity ini, TUMBUH tidak boleh menjadikan Learning sebagai Core Capacity tanpa ontological specification lebih lanjut.

Status **Learning sebagai candidate Core Capacity: HOLD** tetap dipertahankan.

## 15. Competency Boundary

Competency dapat melibatkan mobilisasi knowledge, skills, dispositions, dan resources untuk menghasilkan functioning/performance dalam context tertentu.

Competency ≠ Capacity.

Kompetensi dapat menjadi cara mengorganisasi performance requirements, tetapi tidak menggantikan ontologi Core Capacity TUMBUH.

## 16. Capacity vs Skill Generality

Capacity diharapkan memiliki functional identity yang lebih stabil daripada skill tertentu.

Skill dapat sangat context-specific.

```text
Skill:
lebih spesifik terhadap task/domain

Capacity:
lebih luas secara functional identity
```

“Lebih luas” tidak berarti universal atau bebas konteks.

## 17. Transfer

Skill yang berhasil pada satu task tidak otomatis transfer ke task lain.

Begitu pula learning pada satu context tidak otomatis membuktikan broad Capacity Change.

Transfer harus diperlakukan sebagai empirical/design question sesuai P0057.

## 18. Familiarity Effect

Performance dapat meningkat karena familiarity dengan:

- task;
- instructions;
- format;
- environment;
- assessor;
- routine.

Familiarity effect tidak otomatis berarti Capacity Change.

## 19. Knowledge Test ≠ Critical Thinking Test

Nilai tinggi pada recall atau content knowledge tidak otomatis membuktikan Critical Thinking.

Sebaliknya, critical judgment dapat dipengaruhi oleh knowledge yang relevan.

Karena itu knowledge adalah important resource, tetapi bukan pengganti CT construct.

## 20. Skill Demonstration ≠ Communication Capacity

Kemampuan melakukan satu presentation format tidak otomatis mencakup seluruh Communication capacity.

Evidence perlu mencakup fungsi komunikasi yang relevan: formulation, expression/transmission, reception, dan interpretation sesuai P0042–P0046.

## 21. Skill Demonstration ≠ Collaboration

Keberhasilan menyelesaikan satu group task tidak otomatis membuktikan Collaboration capacity secara luas.

Perlu melihat contribution, coordination, dan joint adjustment sesuai functional identity.

## 22. Learned Routine ≠ Self-Regulation

Routine yang telah dihafal atau otomatis tidak otomatis menunjukkan Self-Regulation.

Self-Regulation membutuhkan capacity untuk monitor dan regulate functioning/tindakan diri terhadap arah atau tujuan yang relevan.

Temuan P0070 tentang automaticity tetap berlaku.

## 23. Learned Procedure ≠ Problem Solving

Mengikuti prosedur yang sudah diajarkan dengan benar tidak otomatis menunjukkan kemampuan menangani discrepancy baru.

Problem Solving membutuhkan representation, strategy generation/selection, dan action adjustment sesuai konteks.

## 24. Learning and Agency

Seseorang dapat belajar banyak hal dalam kondisi yang sangat dikontrol.

Learning tersebut tidak otomatis menunjukkan Agency meningkat.

Agency membutuhkan evidence tentang initiation dan direction of intentional action dalam kondisi nyata.

## 25. Learning and Physical Functioning

Peningkatan skill olahraga atau motorik dapat relevan dengan Physical Functioning, tetapi skill-specific improvement tidak otomatis mewakili seluruh physical functioning.

Evidence harus sesuai functional demand.

## 26. Learning and Social Understanding

Belajar aturan sosial atau terminology tentang emosi tidak otomatis membuktikan Social Understanding dalam interaksi nyata.

Knowledge tentang social functioning ≠ functioning sosial itu sendiri.

## 27. Learning and Self-Regulation

Mempelajari strategi self-regulation tidak sama dengan mampu menggunakannya secara efektif dalam kondisi nyata.

```text
Know the strategy
   ≠
Can use the strategy
   ≠
Capacity has changed
```

## 28. Assessment Inference

Rantai inference yang dipertahankan:

```text
Construct
   ↓
Functional Identity
   ↓
Developmental Change
   ↓
Functioning
   ↓
Performance / Manifestation
   ↓
Evidence
   ↓
Inference
```

Knowledge/skill/learning dapat muncul pada beberapa posisi dalam proses tersebut, tetapi tidak boleh otomatis menggantikan construct.

## 29. Evidence of Capacity Change

Evidence yang lebih informatif untuk Capacity Change membutuhkan pertimbangan:

- perubahan dari waktu ke waktu;
- functional coverage;
- contextual variation;
- opportunity;
- support;
- demand;
- alternative explanations;
- transfer ketika broad claim dibuat.

Tidak ada satu jenis evidence universal yang wajib untuk seluruh capacities.

## 30. Educational Implication

TUMBUH tidak perlu memilih antara “knowledge” atau “capacity”.

Knowledge dan skill tetap penting sebagai bagian dari pendidikan.

Namun secara arsitektural:

```text
Knowledge / Skill / Learning
          ↓
Resources / Processes / Changes
          ↓
Functioning
          ↓
Evidence
          ↓
Inference tentang Capacity
```

Dengan demikian pendidikan tetap dapat mengembangkan knowledge dan skill tanpa mengacaukan level ontologinya dengan Core Capacity.

## 31. Muwashofat Boundary

Muwashofat tidak boleh diterjemahkan menjadi:

- jumlah knowledge;
- jumlah skill;
- learning score;
- mastery score;
- capacity score tunggal.

Muwashofat tetap menjadi normative graduate orientation yang dapat membutuhkan kombinasi knowledge, skill, capacities, values, habits, practices, dan forms of responsibility.

## 32. Core Model vs Progression / Assessment Boundary

Core Model menetapkan distinction konseptual:

- Knowledge ≠ Capacity;
- Skill ≠ Capacity;
- Learning ≠ Capacity Change;
- Practice ≠ Capacity Change;
- Mastery ≠ Capacity;
- Performance ≠ Capacity;
- Learning ≠ Growth;
- familiarity ≠ broad development;
- learned procedure ≠ Problem Solving;
- strategy knowledge ≠ Self-Regulation functioning;
- social knowledge ≠ Social Understanding functioning.

Detail learning progression, mastery criteria, rubric, instrument, scoring, validity, transfer testing, dan evidence sampling tetap berada di `03_PROGRESSION`, `04_ASSESSMENT`, dan `09_RESEARCH`.

## 34. Architectural Conclusion

**PASS — DENGAN GUARDRAIL.**

P0073 memperkuat salah satu boundary paling penting dalam TUMBUH:

> **Belajar sesuatu, mengetahui sesuatu, mampu melakukan sesuatu, dan berkembangnya suatu capacity adalah empat klaim yang tidak boleh dipertukarkan tanpa evidence yang sesuai.**

TUMBUH tetap mengakui Knowledge, Skill, Learning, Practice, dan Mastery sebagai bagian penting dari pendidikan. Namun secara ontologis, istilah-istilah tersebut tidak otomatis menjadi Core Capacity.

Tidak diperlukan Core Model baru.

**Learning tetap HOLD sebagai candidate Core Capacity** sampai terdapat alasan ontologis dan arsitektural yang lebih kuat.

**DESIGNED / CONCEPTUAL ARCHITECTURAL INQUIRY**

Probe ini menetapkan boundary konseptual dan inferensial, bukan bukti empiris bahwa jenis learning tertentu pasti menghasilkan perubahan capacity tertentu.
