# P0098 — Core Capacity Specification v1

Status: PASS — FINAL CONCEPTUAL SPECIFICATION / EMPIRICALLY PROVISIONAL

Eight Core Capacities:
1. Self-Regulation — monitoring, regulation, reorientation of own functioning toward relevant direction/goals.
2. Critical Thinking — examining, analyzing, evaluating, inferring, and explaining information/reasons for appropriate judgment.
3. Communication — forming, transmitting, receiving, and making meaning from messages appropriately to purpose, party, and context.
4. Collaboration — contributing, coordinating, and jointly adjusting action toward shared goals.
5. Physical Functioning — carrying out physical functions required by activity/context demands adequately.
6. Social Understanding — understanding states, perspectives, relations, and social contexts relevant to social functioning.
7. Agency — intentionally initiating and directing action under actual conditions, constraints, opportunities, and support.
8. Problem Solving — understanding and addressing discrepancies between current and desired conditions through obstacle identification, strategy generation/selection, and action adjustment.

Governance: construct first; functional object before dimensions; dimension != indicator; evidence != construct; contextual manifestation != new capacity; integrative pattern != automatically a capacity; normative construct != capacity; capacity profile != person; validation status visible; revision remains possible.

Architectural status: the eight are sufficiently specified for the Core Capacity Architecture stage, but remain empirically provisional. This is not psychometric, causal, effectiveness, or universal cross-cultural validation.
