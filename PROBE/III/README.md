# PROBE III — Capacity Ontology & Architecture Audit

Folder ini mendokumentasikan rangkaian **Probe (P00–P29)** yang membahas ontology, boundary, architecture, dan minimal sufficient set untuk konsep **Capacity** dalam TUMBUH.

> **P = Probe.** Probe adalah unit penyelidikan/stress-test terhadap asumsi arsitektur. P bukan tahap perkembangan, teori, framework, atau versi model.

## Scope

Rangkaian ini merupakan research/design inquiry. Hasilnya tidak otomatis menjadi klaim empiris, teori tervalidasi, atau Capacity Taxonomy final.
