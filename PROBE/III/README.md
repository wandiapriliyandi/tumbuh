# PROBE III — Capacity Ontology & Architecture Audit

Folder ini mendokumentasikan rangkaian **Probe (P00–P30)** yang menguji ontology, boundary, architecture, parsimony, coverage, dan kandidat **Core Capacity** dalam TUMBUH.

> **P = Probe.** Probe adalah unit penyelidikan/stress-test terhadap asumsi arsitektur. P bukan tahap perkembangan, teori, framework, atau versi model.

## Scope

Rangkaian ini merupakan research/design inquiry. Hasil Probe tidak otomatis menjadi klaim empiris, teori tervalidasi, atau Capacity Taxonomy final.

## Archived / superseded numbering

`ARCHIVE/` menyimpan artefak lama yang tetap bernilai sebagai jejak intelektual tetapi tidak lagi menjadi nomor kanonik.

## Documentation rule

Setiap Probe dipertahankan sebagai unit tersendiri agar jejak perkembangan intelektual dapat dilacak. Findings tidak boleh disamakan dengan final architecture; keputusan desain dan validasi empiris harus dicatat pada artefak yang sesuai.

Jika suatu Probe menghasilkan perubahan penomoran atau klasifikasi, artefak lama dipindahkan ke `ARCHIVE/` bila masih memiliki nilai dokumenter, sementara index ini menjadi sumber nomor kanonik.
