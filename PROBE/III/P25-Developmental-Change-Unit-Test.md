# P25 — Developmental Change Unit Test

## Pertanyaan
Jika Capacity berkembang, apa sebenarnya yang berubah?

## Temuan
Knowledge, skill, behavior, habit, performance, competency, dan Capacity Change tidak identik. Performance ↑ tidak otomatis Capacity ↑.

Capacity Change = perubahan state/function suatu Capacity dari waktu ke waktu. Capacity adalah construct; ia tidak diamati langsung. Evidence digunakan untuk inference tentang Capacity.

Transfer/generalization penting tetapi bukan syarat absolut. Capacity dapat memiliki manifestation berbeda pada context berbeda.

Growth ≠ Capacity Change. Capacity Change dinilai terhadap developmental direction dari worldview, educational purpose, dan graduate profile.

## Arsitektur
```text
Capacity State
↓
Context + Opportunity + Support
↓
Functioning
↓
Behavior / Performance
↓
Evidence
↓
Inference about Capacity State
↓
Change over time
```

## Keputusan
**PASS — STRONG.**
