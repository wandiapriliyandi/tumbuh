# P0005 — Reference Frame and Developmental State Representation

**PROBE:** 04 — Core Models Sistem TUMBUH
**Previous Inquiry:** P0004 — Capacity, Competency, Behavior, and Developmental State

## TUMBUH Question

> Jika Developmental State adalah representasi kondisi competency berdasarkan evidence, apa reference frame yang diperlukan agar state dapat ditafsirkan secara bermakna tanpa direduksi menjadi satu skor?

P0003 menemukan bahwa state membutuhkan reference frame, evidence, time, dan bila relevan context. P0004 memperjelas boundary: Capacity adalah domain kemampuan, Competency adalah integrated capability construct, Behavior adalah observable evidence, sedangkan State adalah interpreted current developmental condition.

## Initial Finding

Reference perlu dibedakan dari measurement dan score:

```text
REFERENCE != MEASUREMENT != SCORE
```

Reference adalah acuan interpretasi. Score hanyalah salah satu encoding.

Kandidat reference frame:

```text
REFERENCE FRAME
- Subject
- Domain
- Capacity
- Competency
- Developmental Dimension(s)
- Reference Standard
- Evidence Rules
- Context Conditions
- Time Window
```

## Working Definition

Developmental State adalah representasi terstruktur mengenai kondisi suatu competency pada waktu tertentu, relatif terhadap reference frame yang ditentukan, berdasarkan evidence yang tersedia dan konteks yang relevan.

```text
STATE(t)
= F(competency, dimensions, reference,
    evidence, context, time)
```

`F` bukan formula final; ia menunjukkan bahwa state merupakan hasil interpretasi dari beberapa informasi.

## Important Boundaries

### Reference is not score

Reference menentukan apa yang menjadi acuan. Measurement memperoleh representasi dari evidence. Score adalah salah satu bentuk encoding.

### Dimension is not stage

```text
DIMENSION != STAGE
```

Dimension menjelaskan aspek apa yang berkembang. Stage menjelaskan posisi atau pola perkembangan. Karena itu profile sebaiknya dapat dibentuk sebelum stage ditetapkan.

### Standard is not identical behavior

Standard sebaiknya mendeskripsikan capability condition, bukan memaksa semua orang menampilkan ekspresi perilaku yang identik.

### Context and time matter

State lebih tepat ditulis sebagai `STATE(t)` daripada state tanpa waktu. Context memengaruhi interpretasi ketika context materially changes the meaning of evidence.

## Evidence

State merupakan hasil interpretasi evidence. Satu observasi tidak otomatis sama dengan pola perkembangan.

```text
SINGLE OBSERVATION
        ↓
REPEATED OBSERVATION
        ↓
MULTI-CONTEXT EVIDENCE
        ↓
LONGITUDINAL PATTERN
```

Evidence quality dapat berkaitan dengan relevance, consistency, recency, context coverage, authenticity, dan kecukupan terhadap claim.

## Minimum Useful State

Kandidat minimum:

```text
Competency + Reference + Evidence + Time
```

Context menjadi wajib ketika materially changes interpretation. Developmental dimensions menjadi wajib ketika competency tidak dapat direpresentasikan secara bermakna sebagai satu kondisi.

## Implications

Assessment lebih tepat dipahami sebagai evidence production system, bukan scoring system semata.

Progression sebaiknya diturunkan dari perubahan state:

```text
REFERENCE FRAME
      ↓
STATE PROFILE
      ↓
STATE CHANGE
      ↓
PROGRESSION MODEL
```

Intervention membutuhkan state profile yang cukup kaya untuk menentukan need/gap dan response.

## Candidate Architecture

```text
CHARACTER → CAPACITY → COMPETENCY
                          │
                          ↓
                    REFERENCE FRAME
                          │
                          ↓
                   EVIDENCE CHANNELS
                          ↓
                     INTERPRETATION
                          ↓
                 DEVELOPMENTAL STATE(t)
                          ↓
                        CHANGE
                          ↓
                 DEVELOPMENTAL STATE(t+1)
                          ↓
                      NEED / GAP
                          ↓
                       RESPONSE
                          ↓
                    NEW EVIDENCE
```

Arsitektur ini masih sementara. Ia mulai mengarah pada satu arsitektur relasional dengan beberapa views, bukan banyak model yang berdiri sendiri.
