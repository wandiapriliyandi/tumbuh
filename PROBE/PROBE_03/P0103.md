# P0103 — Decision Scope dan Materiality

**Object of Inquiry:** Principles TUMBUH.

**TUMBUH Question:** Apakah decision scope dan materiality dapat menjadi dasar untuk menentukan intensity of review dan escalation tanpa membuat governance menjadi hierarchy nilai antar-Core Principle?

**Finding:** Materiality harus mengikuti semantic and systemic consequence, bukan ukuran perubahan teks. Decision class dapat menentukan review intensity, tetapi tidak otomatis menentukan authority final.

**Model:** Decision Class → Materiality → Review Intensity → Appropriate Authority → Decision Record → Status → Review.
