# P001 — Mengapa Struktur Repository V2 Dipisahkan Berdasarkan Fungsi?

## Tujuan

Menjelaskan alasan arsitektural mengapa struktur repository V2 disusun berdasarkan fungsi pengetahuan dan fungsi kerja, bukan berdasarkan urutan dokumen dibuat.

## Batasan P001

Probe ini hanya membahas arsitektur repository, organisasi artefak, fungsi folder, navigasi, dan prinsip dokumentasi. Probe ini tidak masuk ke substansi Foundation, Core Model, Progression, Assessment, Intervention, Implementation, Programs, maupun isi substantif sistem TUMBUH.

## Decision

**PASS — FUNCTION-BASED REPOSITORY ARCHITECTURE**
