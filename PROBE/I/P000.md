# P000 — Mengapa TUMBUH Membutuhkan Branch V2?

## Tujuan

Menjelaskan alasan arsitektural dan dokumenter mengapa TUMBUH membutuhkan Branch V2 sebagai ruang evolusi repository tanpa memutus intellectual lineage dari rancangan sebelumnya.

## Batasan P000

Probe ini hanya membahas branch, lineage, evolusi repository, dan alasan dokumenter/arsitektural keberadaan V2. Probe ini tidak membahas Foundation, Core Model, Progression, Assessment, Intervention, Implementation, Programs, atau substansi sistem TUMBUH.

## Decision

**PASS — V2 diperlukan sebagai ruang evolusi arsitektur TUMBUH.**
