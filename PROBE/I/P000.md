# P000 — Mengapa TUMBUH Membutuhkan Branch V2?

## Tujuan

Menjelaskan alasan mengapa TUMBUH membutuhkan Branch V2 sebagai ruang evolusi arsitektur dan dokumentasi, tanpa memutus intellectual lineage dari rancangan sebelumnya.

## 1. V2 sebagai Ruang Evolusi

Branch V2 dibutuhkan karena pengembangan TUMBUH tidak hanya berupa penambahan isi, tetapi juga dapat mencakup penataan ulang arsitektur repository, batas antarartefak, dan cara pengembangan didokumentasikan.

V2 memberi ruang untuk melakukan perubahan tersebut tanpa menghapus atau mencampurkan sejarah perkembangan sebelumnya.

## 2. V2 Bukan TUMBUH yang Terputus dari V1

V2 tidak diperlakukan sebagai sistem yang sama sekali baru. Hubungannya adalah evolusioner:

**V1 → review → refinement → restructuring → V2**

Dengan demikian, V2 tetap memiliki intellectual lineage terhadap perkembangan sebelumnya.

## 3. Branch sebagai Penanda Fase Arsitektur

Dalam konteks repository, branch bukan hanya mekanisme Git. Branch juga dapat menjadi penanda bahwa sebuah rancangan sedang dikembangkan dalam fase arsitektur tertentu.

Branch V2 memungkinkan perubahan struktural dilakukan secara eksplisit dan dapat dilacak.

## 4. Mengapa Tidak Langsung Mengubah Struktur Lama?

Mengubah struktur lama secara langsung dapat mencampurkan kondisi historis dengan rancangan baru. Branch V2 menyediakan boundary yang lebih jelas antara struktur yang sedang dievaluasi dan struktur yang sedang dikembangkan.

Tujuannya bukan mempertahankan semua keputusan lama, melainkan mempertahankan kemampuan untuk mengetahui dari mana keputusan baru berasal.

## 5. Nilai Dokumenter V2

V2 membantu menjaga:

1. kontinuitas sejarah pengembangan;
2. keterlacakan perubahan arsitektur;
3. ruang untuk restrukturisasi;
4. pemisahan kondisi lama dan rancangan baru; dan
5. kemampuan untuk menjelaskan alasan perubahan di kemudian hari.

## 6. Decision

**PASS — V2 Diperlukan sebagai Ruang Evolusi Arsitektur.**

Branch V2 dipertahankan sebagai lineage pengembangan yang memungkinkan restrukturisasi dan penyempurnaan dilakukan secara eksplisit tanpa memutus hubungan dengan perkembangan sebelumnya.

## Batasan P000

Probe ini hanya membahas alasan keberadaan Branch V2 sebagai ruang evolusi repository dan arsitektur dokumentasi. Probe ini **tidak** membahas substansi Foundation, Core Model, Progression, Assessment, Intervention, Implementation, Programs, maupun isi substantif sistem TUMBUH.
