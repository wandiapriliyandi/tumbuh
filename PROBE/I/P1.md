# P001 — Mengapa Struktur Repository V2 Dipisahkan Berdasarkan Fungsi?

## Tujuan

Menjelaskan prinsip organisasi repository V2 dan alasan struktur dipisahkan berdasarkan fungsi pengetahuan dan fungsi kerja, bukan semata berdasarkan urutan dokumen dibuat.

## Batasan P001

Probe ini hanya membahas arsitektur repository, fungsi folder, organisasi artefak, dan prinsip navigasi/dokumentasi. Probe ini tidak membahas isi atau substansi Foundation, Core Model, Progression, Assessment, Intervention, Implementation, Programs, atau teori perkembangan TUMBUH.

## Decision

**PASS — FUNCTION-BASED REPOSITORY ARCHITECTURE.**
