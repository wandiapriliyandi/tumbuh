# PROBE 11 — Curriculum Architecture ketika Pesantren Memiliki Madrasah

## Object of Inquiry

Arsitektur kurikulum Sistem TUMBUH pada konteks pesantren yang memiliki madrasah formal.

## TUMBUH Question

Jika pesantren memiliki madrasah, apakah TUMBUH membutuhkan satu kurikulum terintegrasi, dua kurikulum yang terkoordinasi, atau satu sistem perkembangan dengan beberapa curriculum vehicles?

## Fokus Inquiry

PROBE ini mengkaji hubungan antara:

- kurikulum madrasah;
- kurikulum dan kehidupan pesantren;
- formation curriculum;
- academic curriculum;
- curriculum as lived experience;
- graduate profile;
- progression;
- assessment;
- learning experiences; dan
- ekosistem pendidikan santri.

## Boundary

PROBE ini tidak dimaksudkan untuk langsung menyusun kurikulum mata pelajaran madrasah atau kurikulum kepesantrenan secara teknis. Fokusnya adalah menemukan arsitektur hubungan keduanya di dalam Sistem TUMBUH.

## Repository Destination

Temuan PROBE ini berpotensi menjadi dasar bagi pengembangan bagian kurikulum, learning architecture, progression, assessment, programs, methods, dan implementation pada repository TUMBUH.

## Metodologi

Pertanyaan boleh berkembang mengikuti hasil inquiry, tetapi setiap P harus tetap kembali kepada Object of Inquiry dan kebutuhan Sistem TUMBUH. Setiap hasil substantif perlu menghasilkan implikasi bagi TUMBUH dan dapat ditelusuri menuju repository.
