# Domain 03: Capacity Framework (Taksonomi Kapasitas 10 Muwashafat Karakter Santri)

Direktori ini memuat taksonomi, standar kompetensi, dan profil kapasitas holistik bagi 3 entitas utama: **Santri**, **Guru/Musyrif**, dan **Sistem Lembaga**, yang mencakup **10 Karakter Utama Santri (*Muwashafat*)** yang terintegrasi dengan CASEL Social-Emotional Learning.
