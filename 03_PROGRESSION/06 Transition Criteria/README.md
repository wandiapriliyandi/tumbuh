# 03_PROGRESSION / 06 Transition Criteria

**Status:** PROPOSED — Wave 3 baseline

## Purpose
Menentukan kriteria perpindahan dukungan atau tingkat tantangan berdasarkan evidence yang relevan.

## Transition Rule
```text
Evidence → Review → Context Check → Decision → Trial → Monitor → Confirm / Revert
```

## Core Criteria
Keputusan transisi mempertimbangkan:
1. konsistensi performa;
2. tingkat dukungan yang masih diperlukan;
3. kemampuan menerapkan pada konteks relevan;
4. risiko dan safeguarding;
5. kesiapan lingkungan/pengasuh;
6. bukti respons setelah perubahan dukungan.

## Boundary
Transition criteria bukan penetapan tahap perkembangan universal dan tidak boleh digunakan sebagai label permanen bagi santri.
