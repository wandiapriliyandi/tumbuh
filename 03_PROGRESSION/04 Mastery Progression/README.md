# 03_PROGRESSION / 04 Mastery Progression

**Status:** PROPOSED — Wave 3 baseline

## Purpose
Menentukan bagaimana TUMBUH membedakan sekadar exposure/performance sesaat dari penguasaan yang relatif stabil dan dapat ditransfer.

## Mastery Logic
```text
Performance → Consistency → Independence → Transfer → Sustained Application
```

## Minimum Evidence
Mastery tidak ditetapkan dari satu observasi. Bukti perlu mempertimbangkan konsistensi, konteks, dukungan yang dibutuhkan, dan transfer ke situasi relevan.

## Boundary
Mastery criteria bersifat construct-specific. Tidak boleh menggunakan satu ambang universal untuk seluruh kapasitas.
