## 1. Operasionalisasi Form Functional Behavior Assessment (FBA) Diagnostik BK

Form FBA digunakan oleh Konselor BK untuk mengidentifikasi fungsi perilaku maladaptif santri Tier 3:

```mermaid
graph TD
    FBADiagnosticForm["4 Elemen Utama Form FBA Diagnostik"]
    FBADiagnosticForm --> AntecedentA["1. Antecedent (A - Pemicu Situasional): Waktu, lokasi, lawan bicara, & kondisi fisik/emosional."]
    FBADiagnosticForm --> BehaviorB["2. Behavior (B - Perilaku Faktual): Perilaku spesifik terukur (misal: membanting pintu / berteriak)."]
    FBADiagnosticForm --> ConsequenceC["3. Consequence (C - Konsekuensi Lingkungan): Respon musyrif/rekan yang tidak sengaja memperkuat."]
    FBADiagnosticForm --> HypothesizedFunc["4. Hypothesized Function (Fungsi Perilaku): Escape (menghindar) / Attention (mencari perhatian)."]
```

---

## 2. Penggunaan Sebagai Dasar Rencana BIP

Hasil FBA menjadi dokumen hukum dasar untuk merumuskan dokumen Behavior Intervention Plan (BIP) Tier 3.
