## 1. Operasionalisasi Form Incident Report A-B-C Data

Form ini digunakan untuk mencatat secara objektif kejadian insiden perilaku sedang/berat di lingkungan pesantren:

```markdown
# FORM INCIDENT REPORT (A-B-C DATA)
ID Incident: [INC-YYYYMMDD-XXX] | Waktu Kejadian: [HH:MM] | Lokasi: [Asrama/Masjid/Kelas]
Nama Santri Terlibat: _______________________ | Nama Musyrif Pelapor: _______________________

## 1. Antecedent (A) - Peristiwa Sebelum Kejadian
- Apa yang sedang terjadi tepat sebelum insiden? (Misal: Pergantian jam KBM / berebut alat mandi)
- Catatan: ______________________________________________________________________________

## 2. Behavior (B) - Perilaku Objektif Terukur
- Uraikan perilaku nyata tanpa opini emosional: (Misal: Mengucapkan kata kasar / melempar sandal)
- Catatan: ______________________________________________________________________________

## 3. Consequence (C) - Respon Lingkungan Langsung
- Apa respon musyrif / kawan seketika itu? (Misal: Musyrif melakukan Restorative Chat privat)
- Catatan: ______________________________________________________________________________
```
