# 11 Tools (Kerangka Kerja Instrumen & Perangkat Digital Pesantren TUMBUH)

Domain ini memuat instrumen asesmen, rubrik penilaian, templat runbook operasional, serta spesifikasi arsitektur perangkat digital di ekosistem **TUMBUH** yang terbagi dalam **8 Sub-Domain Utama**: Assessment Tools, Observation Tools, Reflection Tools, Coaching Tools, Mentoring Tools, Documentation Tools, Reporting Tools, dan Digital Tools.

---

## Arsitektur Ekosistem Perangkat Pembinaan & Digital

```mermaid

    ToolsCore["Ekosistem Perangkat Pembinaan & Digital TUMBUH"]
    ToolsCore --> AssessTools["1. Assessment Tools (Rubrik 10 Muwashafat, Self-Assessment, & FBA Form)"]
    ToolsCore --> ObsTools["2. Observation Tools (Logbook Harian Musyrif, Checklist Adab, & Incident Report)"]
    ToolsCore --> RefTools["3. Reflection Tools (Jurnal Refleksi Malam 3-Q, Circle of Gratitude, & Muhasabah)"]
    ToolsCore --> CoachTools["4. Coaching Tools (GROW Worksheet, Kartu CICO Tier 2, & Form BIP Tier 3)"]
    ToolsCore --> MentorTools["5. Mentoring Tools (Runbook 1-on-1, Peer Buddy Checklist, & Homesickness Care)"]
    ToolsCore --> DocTools["6. Documentation Tools (Notulensi Rapat, Form Ishlah Restoratif, & Portofolio)"]
    ToolsCore --> RepTools["7. Reporting Tools (Raport Karakter PBIS, EWS Report, & Parent Summary)"]
    ToolsCore --> DigTools["8. Digital Tools (Logbook App, Parent Portal App, & Database Relasional/API)"]
```
