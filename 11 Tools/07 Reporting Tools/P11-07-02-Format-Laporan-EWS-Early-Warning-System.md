## 1. Operasionalisasi Format Laporan EWS (Early Warning System)

Laporan EWS dipicu otomatis oleh sistem analitik PBIS ketika terdeteksi indikator risiko:

```markdown
# LAPORAN EARLY WARNING SYSTEM (EWS ALERT)
ID EWS: [EWS-YYYYMMDD-XXX] | Tingkat Risiko: [ ] Kuning (Tier 2)  [ ] Merah (Tier 3)
Nama Santri: [_______________] | Kelas/Kamar: [________] | Tanggal Pemicu: [YYYY-MM-DD]

## 1. Indikator Pemicu Risiko (Trigger Flags)
- [ ] Penurunan Ketepatan Sholat Berjamaah 3 Hari Berturut-turut.
- [ ] Penurunan Skor CICO Harian di bawah 70% Selama 1 Pekan.
- [ ] Catatan Perubahan Emosional / Penarikan Diri Sosial dari Musyrif.

## 2. Rekomendasi Tindak Lanjut Terpadu
- Pembahasan Kasus dalam Rapat Sabtu Pagi: Ya / Tidak.
- Aktivasi Pendampingan Privat Konselor BK (Sesi 1-on-1).
- Komunikasi Kolaboratif dengan Orang Tua Santri.
```
