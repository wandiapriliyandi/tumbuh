## 1. Operasionalisasi Lembar Muhasabah Penataan Hati

Lembar kerja ini membantu santri melakukan diagnosis mandiri penyakit hati (*Tazkiyatun Nafs*) secara berkala:

| Area Penataan Hati (*Tazkiyah*) | Pertanyaan Refleksi Mandiri | Solusi Amalan Penawar (*Ad-Dawa'*) |
| :--- | :--- | :--- |
| **1. Kebersihan Niat (Ikhlas)** | *Apakah kebaikan saya hari ini ingin dilihat kawan / dipuji musyrif?* | Memperbanyak amalan tersembunyi (*Amal Sirr*) tanpa sepengetahuan orang lain. |
| **2. Kelola Amarah (Ghadhab)** | *Apakah saya mudah meledak marah saat keinginan saya tidak dituruti?* | Membaca Ta'awwuz, berwudhu, & mengubah posisi tubuh saat emosi naik. |
| **3. Kerendahan Hati (Tawadhu')**| *Apakah saya merasa lebih mulia / pintar dibanding kawan se-kamar?* | Mengingat asal fitrah penciptaan & menghormati setiap kebaikan kawan. |
