# 04_ASSESSMENT / 05 Multi-Source Assessment

**Status:** PROPOSED — Wave 4 baseline

Multi-source assessment menggabungkan evidence yang relevan dari lebih dari satu perspektif untuk mengurangi ketergantungan pada satu pengamat/sumber.

Perbedaan antar sumber tidak otomatis dianggap error; discrepancy dapat menjadi informasi yang perlu ditabayyun.
