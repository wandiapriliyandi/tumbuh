# 04_ASSESSMENT / 01 Architecture

**Status:** DESIGNED — Wave 4 baseline

Assessment TUMBUH adalah sistem pengumpulan dan interpretasi evidence untuk memahami perkembangan dan menentukan dukungan. Assessment bukan sekadar pemberian skor.

Alur: **Construct → Indicator → Evidence → Interpretation → Decision → Monitoring**.

Assessment harus selaras dengan tujuan construct, konteks, etika, dan safeguarding.
