# Implementation

Bagian ini menjelaskan bagaimana TUMBUH diwujudkan dalam lembaga: model penerapan, desain organisasi, struktur, peran, hubungan kerja, alur, serta rancangan program, metode, dan alat.

Implementation bukan kumpulan SOP lembaga. Dokumen teknis seperti SOP, job description, tatib, dan proker merupakan produk operasional yang dapat dikembangkan oleh masing-masing lembaga berdasarkan kerangka implementasi TUMBUH.
