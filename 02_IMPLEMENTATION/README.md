# Implementation

Bagian ini menjelaskan **bagaimana TUMBUH diwujudkan dalam lembaga**: model penerapan, desain organisasi, struktur, peran, hubungan kerja, alur, serta rancangan program, metode, dan alat.

`02_IMPLEMENTATION` menerjemahkan substansi Fundamental ke dalam konteks kelembagaan. Ia menjawab pertanyaan: **bagaimana sistem ini hidup dan bekerja di sebuah lembaga?**

Implementation bukan kumpulan SOP lembaga dan bukan tempat menetapkan ulang substansi inti TUMBUH. Dokumen teknis seperti SOP, job description, tata tertib, dan proker merupakan produk operasional yang dapat dikembangkan oleh masing-masing lembaga berdasarkan kerangka Fundamental dan Implementation.

## Batas dengan layer lain

- `01_FUNDAMENTAL/` menetapkan substansi dan arsitektur inti TUMBUH.
- `PROBE/` menjelaskan proses penyelidikan dan alasan keputusan desain.
- `08_SOURCES_AND_EVIDENCE/` menyediakan sumber/evidence untuk penelusuran klaim dan keputusan.
- `03_OPERATIONAL/` berisi perangkat kerja konkret yang dipakai lembaga.

Jadi alurnya bukan menyalin Fundamental menjadi SOP, tetapi menerjemahkan **substansi → desain kelembagaan → produk kerja**.
