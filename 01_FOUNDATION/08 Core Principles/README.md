# 08 Core Principles

Core Principles adalah prinsip yang menjadi **pagar bagi seluruh desain dan praktik TUMBUH**.

Bagian Foundation sebelumnya menjelaskan cara TUMBUH memandang realitas, pengetahuan, manusia, perkembangan, pendidikan, kepemimpinan, dan perubahan. Di sini semuanya diringkas menjadi prinsip yang perlu tetap dijaga ketika TUMBUH mulai diterjemahkan menjadi bagian-bagian sistem yang lebih teknis.

Core Principles bukan kumpulan metode. Ia juga bukan SOP, rubric, instrumen, atau program. Metode dan cara kerja dapat berubah ketika konteks dan bukti berubah. Prinsip menjadi batas agar perubahan tersebut tidak menghilangkan arah dasar TUMBUH.

## Dari Foundation ke Core Model

Urutannya sekarang menjadi:

**Worldview → Epistemology → Human Nature → Human Development → Education → Leadership → Change → Core Principles → Core Model**

Core Principles menjadi jembatan. Ia tidak menggantikan Foundation, tetapi juga belum masuk ke rincian Core Model.

Karena itu, ketika kita mulai merumuskan Graduate Profile, Capacity Architecture, dan bagian Core Model lainnya, setiap keputusan desain perlu dapat ditelusuri kembali ke prinsip yang sudah dibangun di Foundation.
