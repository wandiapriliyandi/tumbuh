# 08 Core Principles

Core Principles adalah prinsip yang menjadi **pagar bagi seluruh desain dan praktik TUMBUH**.

Bagian Foundation sebelumnya menjelaskan cara TUMBUH memandang realitas, pengetahuan, manusia, perkembangan, pendidikan, kepemimpinan, dan perubahan. Di sini semuanya diringkas menjadi prinsip yang perlu tetap dijaga ketika TUMBUH mulai diterjemahkan menjadi bagian-bagian sistem yang lebih teknis.

Core Principles bukan kumpulan metode. Ia juga bukan SOP, rubric, instrumen, atau program. Metode dan cara kerja dapat berubah ketika konteks dan bukti berubah. Prinsip menjadi batas agar perubahan tersebut tidak menghilangkan arah dasar TUMBUH.

## Dokumen utama

**[P2-01 — Core Principles TUMBUH](./P2-01-Core-Principles-Canonical.md)** adalah satu-satunya dokumen kanonik untuk prinsip inti TUMBUH.

Dokumen lain pada folder ini tidak boleh membuat daftar prinsip alternatif yang berdiri sendiri.

## Status Canonical

Sepuluh Core Principles telah melalui rekonstruksi dan audit pada **[P0010 — Rekonstruksi Core Principles](../../PROBE/II/P0010-Rekonstruksi-Core-Principles-Dari-Warisan-V1-ke-10-Prinsip-Canonical-V2.md)**.

Hasil P0010:

- 10/10 prinsip dipertahankan.
- Tidak ada prinsip tambahan yang diperlukan berdasarkan reverse audit.
- Tidak ada prinsip yang dihapus berdasarkan uji redundansi.
- Gagasan penting V1 yang tidak menjadi Core Principle direlokasi atau disintesis ke layer yang sesuai berdasarkan fungsi arsitekturalnya.
- Nomor 1–10 adalah urutan penyajian, bukan ranking kepentingan.

Dengan demikian, **P2-01 merupakan daftar canonical Core Principles untuk TUMBUH v2.0.0**.

Status canonical tidak berarti prinsip kebal terhadap revisi di masa depan. Revisi tetap harus melalui proses yang dapat ditelusuri, memiliki alasan yang jelas, dan mengikuti governance TUMBUH.

## Dari Foundation ke Core Model

Urutannya sekarang menjadi:

**Worldview → Epistemology → Human Nature → Human Development → Education → Leadership → Change → Core Principles → Core Model**

Core Principles menjadi jembatan. Ia tidak menggantikan Foundation, tetapi juga belum masuk ke rincian Core Model.

Karena itu, ketika kita mulai merumuskan Graduate Profile, Capacity Architecture, dan bagian Core Model lainnya, setiap keputusan desain perlu dapat ditelusuri kembali ke prinsip yang sudah dibangun di Foundation.

## Batas Arsitektural

Core Principles harus tetap berada pada tingkat **prinsip lintas sistem**. Istilah atau gagasan penting dari V1 tidak harus menjadi Core Principle apabila fungsi yang lebih tepat berada pada layer lain.

Contohnya:

- Triad Pertumbuhan → Core Model / Growth Architecture.
- Qudwah → Education / Leadership dan praktik terkait.
- Data dan Tabayyun → Epistemology serta konsekuensi keputusan pada Core Principle #7.
- Tadarruj dan Istiqamah → Human Development / Progression / Change sesuai fungsi.
- Firm & Kind → Intervention / Design.

Karena itu, tidak munculnya sebuah istilah V1 di daftar sepuluh prinsip **tidak berarti konsep tersebut dihapus dari TUMBUH**.
