# Core Principles

Folder ini memuat rumusan prinsip paling mendasar TUMBUH.

Core Principles berada setelah Philosophy dan menjadi dasar bagi prinsip-prinsip yang lebih spesifik: Design, Learning, Development, Assessment, Intervention, dan Implementation Principles.

## Isi Folder

1. `Core-Principles.md` — rumusan utama prinsip inti TUMBUH.
2. `Principle-Hierarchy.md` — kedudukan dan hubungan Core Principles dengan prinsip turunan.
3. `Principle-Application.md` — cara prinsip diterjemahkan menjadi pertimbangan dalam desain dan pengambilan keputusan.
4. `Guardrails.md` — batas dan pertanyaan uji untuk menjaga agar pengembangan TUMBUH tetap konsisten.
5. `Traceability.md` — pola penelusuran hubungan antara Philosophy, Core Principles, prinsip turunan, framework, dan praktik.

## Posisi dalam Arsitektur

```text
Philosophy
    ↓
Core Principles
    ↓
Specific Principles
    ↓
Framework
    ↓
Practice
```

Folder ini tidak dimaksudkan menjadi tempat seluruh kajian sumber. Sumber, argumentasi, dan proses pengujian berada pada lapisan PROBE, research, dan sources/evidence. Repository menyimpan rumusan yang sudah dibakukan atau sedang disiapkan untuk dibakukan.
