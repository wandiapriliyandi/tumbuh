# 08 Core Principles

Core Principles adalah prinsip lintas sistem yang menjadi **pagar bagi seluruh desain dan praktik TUMBUH**.

Foundation menjelaskan cara TUMBUH memandang realitas, pengetahuan, manusia, perkembangan, pendidikan, kepemimpinan, dan perubahan. Core Principles menyintesis fondasi tersebut menjadi prinsip yang harus tetap dijaga ketika TUMBUH diterjemahkan ke layer sistem berikutnya.

Core Principles bukan kumpulan metode. Ia bukan SOP, rubric, instrumen, atau program. Metode dan cara kerja dapat berubah ketika konteks dan bukti berubah; prinsip menjaga agar perubahan tersebut tidak menghilangkan arah dasar TUMBUH.

## Dokumen Canonical

**[01-Core-Principles.md](./01-Core-Principles.md)** adalah dokumen canonical Core Principles TUMBUH v2.0.0.

Dokumen ini memuat **10 Core Principles**. Nomor 1–10 adalah urutan penyajian, bukan ranking kepentingan.

## Dasar Rekonstruksi

Daftar canonical ini merupakan hasil rekonstruksi dan reverse audit, bukan sekadar pemindahan daftar V1.

- `PROBE/II/P0008-Mengapa-Core-Principles-Menjadi-Domain-Foundation.md` menjelaskan mengapa Core Principles menjadi domain Foundation.
- `PROBE/II/P0010-Rekonstruksi-Core-Principles-Dari-Warisan-V1-ke-10-Prinsip-Canonical-V2.md` mendokumentasikan audit dan keputusan canonicalisasi.

Hasil P0010:

- 10/10 prinsip dipertahankan.
- Tidak ada prinsip tambahan yang diperlukan berdasarkan reverse audit.
- Tidak ada prinsip yang dihapus berdasarkan uji redundansi.
- Konsep penting V1 yang tidak menjadi Core Principle direlokasi atau disintesis ke layer yang lebih tepat berdasarkan fungsi arsitekturalnya.

## Dari Foundation ke Core Model

Urutannya:

**Worldview → Epistemology → Human Nature → Human Development → Education → Leadership → Change → Core Principles → Core Model**

Core Principles menjadi jembatan antara Foundation dan Core Model. Ia tidak menggantikan Foundation dan belum masuk ke rincian kapasitas, progression, assessment, intervention, atau program.

## Batas Arsitektural

Konsep V1 tidak harus dipertahankan sebagai prinsip apabila fungsi utamanya berada pada layer lain. Contoh hasil rekonstruksi:

- Triad Pertumbuhan → Core Model / Growth Architecture.
- Qudwah → Education / Leadership dan praktik terkait.
- Data dan Tabayyun → Epistemology serta konsekuensi keputusan pada Core Principle #7.
- Tadarruj dan Istiqamah → Human Development / Progression / Change.
- Firm & Kind → Intervention / Design.

Jadi, tidak munculnya istilah V1 dalam daftar sepuluh prinsip **tidak berarti konsep tersebut dihapus dari TUMBUH**.

## Aturan Revisi

Status canonical bukan berarti kebal terhadap revisi. Revisi harus memiliki alasan yang jelas dan dapat ditelusuri melalui PROBE, evidence, serta governance TUMBUH.
