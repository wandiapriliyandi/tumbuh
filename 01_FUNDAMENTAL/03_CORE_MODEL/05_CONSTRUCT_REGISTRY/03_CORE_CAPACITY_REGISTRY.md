# Core Capacity Registry

## 8 Core Capacities TUMBUH

| ID | Core Capacity | Functional Object |
|---|---|---|
| CC-01 | Self-Regulation | Functioning dan tindakan diri relatif terhadap arah/tujuan yang relevan |
| CC-02 | Critical Thinking | Informasi, klaim, alasan, dan judgment yang relevan dengan keyakinan/tindakan |
| CC-03 | Communication | Pesan dan makna dalam interaksi |
| CC-04 | Collaboration | Joint action dan contribution menuju shared goals |
| CC-05 | Physical Functioning | Physical functioning yang diperlukan untuk aktivitas/tuntutan konteks |
| CC-06 | Social Understanding | Keadaan, perspektif, relasi, dan konteks sosial yang relevan |
| CC-07 | Agency | Intentional action under real conditions |
| CC-08 | Problem Solving | Gap kondisi aktual-target, hambatan, dan strategi penanganannya |

## Functional Dimensions

- **CC-01 Self-Regulation:** Monitoring; Regulation; Reorientation.
- **CC-02 Critical Thinking:** Examination/Analysis; Evaluation; Inference/Judgment; Explanation/Justification.
- **CC-03 Communication:** Formulation; Expression/Transmission; Reception; Interpretation.
- **CC-04 Collaboration:** Contribution; Coordination; Joint Adjustment.
- **CC-05 Physical Functioning:** Mobility/Movement; Manipulation/Control; Endurance/Function relative to Demand.
- **CC-06 Social Understanding:** Perspective Interpretation; Relational Interpretation; Social-Context Interpretation.
- **CC-07 Agency:** Initiation; Direction; Intentional Action under Conditions.
- **CC-08 Problem Solving:** Problem Representation; Strategy Generation/Selection; Action Adjustment.

## Registry Rule

Delapan capacity adalah keputusan arsitektural TUMBUH saat ini. Status konseptualnya ditetapkan; status empirisnya tetap provisional sampai didukung validation yang sesuai.

## Non-Equivalence

Registry ini tidak menganggap capacity sebagai process, resource, performance, normative trait, context, atau program.

## Status

**Canonical conceptual registry / empirically provisional.**
