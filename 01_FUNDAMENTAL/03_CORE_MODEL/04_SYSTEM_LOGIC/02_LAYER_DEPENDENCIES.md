# Layer Dependencies — Ketergantungan Antar-Layer

## Gampangnya

Setiap domain TUMBUH mempunyai pekerjaan yang berbeda. Layer dependency menjelaskan **apa yang menjadi dasar bagi layer berikutnya tanpa membuatnya mengambil alih fungsi layer tersebut**.

## Canonical Dependencies

| Dari | Ke | Fungsi hubungan |
|---|---|---|
| Worldview / Normative Direction | Graduate Profile | memberi arah normatif |
| Graduate Profile | Core Model | memberi arah tentang functioning yang relevan |
| Growth Ecology | Growth Mechanism | memberi konteks tempat mekanisme berlangsung |
| Growth Mechanism | Core Capacity Architecture | menjelaskan bagaimana kapasitas dapat berubah |
| Core Capacity Architecture | Progression | menyediakan construct yang dikembangkan |
| Progression | Assessment | memberi orientasi perkembangan yang relevan untuk diamati |
| Assessment | Intervention | memberi evidence untuk keputusan dukungan |
| Intervention | Implementation | diterjemahkan ke pelaksanaan nyata |
| Implementation | Evidence & Research | menghasilkan data dan pengalaman implementasi untuk ditinjau |
| Evidence & Research | Continuous Improvement | memberi dasar revisi ketika warranted |

## Dependency ≠ Causality

Ketergantungan arsitektural berarti suatu layer membutuhkan definisi, arah, atau informasi dari layer lain agar berfungsi secara koheren.

Contoh:

> Assessment bergantung pada construct yang didefinisikan Core Model.

Ini tidak berarti:

> Core Model menyebabkan hasil assessment.

## Layer Ownership

Setiap layer harus mempertahankan wilayah kerjanya:

- Foundation menetapkan landasan dan arah normatif.
- Core Model menjelaskan mekanisme dan construct inti.
- Progression menjelaskan perkembangan.
- Assessment menjelaskan evidence dan inference.
- Intervention menjelaskan respons pengembangan.
- Implementation menjelaskan pelaksanaan sistem.
- Research/Evidence menguji dan memperbaiki sistem.

## Boundary Test

Jika sebuah dokumen mulai melakukan pekerjaan utama layer lain, periksa kemungkinan **layer collision**.

Contoh:

- Progression tidak boleh mendefinisikan ulang Core Capacity.
- Assessment tidak boleh mendefinisikan construct hanya berdasarkan instrumen.
- Intervention tidak boleh diam-diam menjadi Growth Mechanism.
- Program tidak boleh menjadi definisi Core Model.
