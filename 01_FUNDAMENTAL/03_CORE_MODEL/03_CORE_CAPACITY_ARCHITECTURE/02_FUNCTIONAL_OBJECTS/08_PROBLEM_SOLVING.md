# Functional Object 08 — Problem Solving

## Gampangnya

**Apa yang ditangani oleh Problem Solving?**

Yang menjadi objek adalah **kesenjangan antara keadaan sekarang dan keadaan yang ingin dicapai**, beserta hambatan dan kemungkinan jalan untuk menanganinya.

## Functional Object

> **Gap antara kondisi aktual dan kondisi yang dituju, bersama hambatan, batasan, dan strategi yang relevan untuk menangani gap tersebut.**

Jadi Problem Solving bukan sekadar "orang pintar mencari jawaban". Fokusnya adalah **menangani sebuah masalah nyata**.

## Contoh sederhana

Santri harus mengumpulkan tugas besok, tetapi sebagian bahan belum tersedia.

Objek Problem Solving adalah **kesenjangan antara kondisi saat ini dan kondisi yang dibutuhkan**, termasuk hambatan yang menyebabkan kesenjangan tersebut dan pilihan jalan keluarnya.

## Yang Bukan Functional Object

Bukan:
- kecerdasan umum;
- kreativitas saja;
- pengetahuan saja;
- satu metode pemecahan masalah;
- kecepatan menyelesaikan tugas;
- atau keberhasilan akhir semata.

## Hubungan dengan Functional Dimensions

Gap dan hambatan tersebut dapat dilihat melalui:

`PROBLEM REPRESENTATION → STRATEGY GENERATION / SELECTION → ACTION ADJUSTMENT`

Ini adalah struktur fungsional, bukan urutan wajib dalam semua masalah.

## Hubungan dengan Capacity

**Core Capacity:** Problem Solving  
**Functional Object:** Gap antara kondisi aktual dan kondisi yang dituju  
**Functional Dimensions:** Problem Representation, Strategy Generation/Selection, Action Adjustment

> **Capacity = kemampuan apa?**  
> **Functional Object = kemampuan itu bekerja terhadap apa?**

## Batas

Keberhasilan akhir tidak otomatis membuktikan kualitas Problem Solving. Hasil juga dapat dipengaruhi tools, resources, informasi, waktu, support, dan kondisi eksternal.
