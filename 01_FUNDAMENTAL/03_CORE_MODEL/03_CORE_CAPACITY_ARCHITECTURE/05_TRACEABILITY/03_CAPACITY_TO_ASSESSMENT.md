# Capacity to Assessment Trace

## Gampangnya

Assessment TUMBUH harus dapat ditelusuri kembali ke construct yang hendak diamati. Assessment tidak boleh mendefinisikan capacity secara diam-diam.

## Canonical Chain

```text
Core Capacity
      ↓
Functional Object
      ↓
Functional Dimensions
      ↓
Observable Manifestations
      ↓
Evidence Source
      ↓
Assessment Interpretation
```

## Prinsip

1. **Construct-first** — mulai dari capacity, bukan dari instrumen yang sudah tersedia.
2. **Function-focused** — assessment mencari bukti functioning, bukan sekadar label atau sifat.
3. **Context-aware** — manifestasi dibaca bersama konteks, tuntutan, dukungan, dan kondisi pengamatan.
4. **Multi-source when needed** — satu sumber evidence tidak selalu cukup untuk mewakili construct kompleks.
5. **Inference-limited** — kesimpulan tidak boleh lebih luas daripada evidence yang tersedia.

## Contoh

Untuk Self-Regulation:

```text
Self-Regulation
→ Monitoring / Regulation / Reorientation
→ Manifestasi dalam konteks
→ Evidence
→ Interpretasi assessment
```

Bukan:

```text
Checklist perilaku
→ dianggap langsung sebagai Self-Regulation
```

## Boundary

Assessment score bukan capacity. Satu skor, observasi, atau performa pada satu tugas tidak otomatis mewakili keseluruhan construct.

Assessment juga tidak boleh digunakan untuk membuat klaim kausal tentang mengapa seseorang berkembang tanpa evidence yang sesuai.
