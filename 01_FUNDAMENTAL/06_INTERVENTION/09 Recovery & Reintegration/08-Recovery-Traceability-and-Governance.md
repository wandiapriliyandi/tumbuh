## 1. Rantai Keterlacakan Tujuh Simpul (*Seven-Node Traceability Chain*)

Setiap langkah penanganan pemulihan dan kepulangan santri wajib terdokumentasi dalam alur kanonikal:

```text
┌─────────────────┐      ┌─────────────────┐      ┌─────────────────┐      ┌─────────────────┐
│ 1. NEED / COND. │ ───► │  2. RECOVERY    │ ───► │  3. TARGETED    │ ───► │ 4. READINESS    │
│ (Kondisi Awal   │      │      GOAL       │      │     SUPPORT     │      │     REVIEW      │
│  Pasca-Krisis)  │      │ (Sasaran Fungsi)│      │ (Rencana Terapi)│      │ (Audit Kesiapan)│
└─────────────────┘      └─────────────────┘      └─────────────────┘      └────────┬────────┘
                                                                                    │
                         ┌─────────────────┐      ┌─────────────────┐               │
                         │ 7. REVIEW /     │ ◄─── │  6. RESPONSE    │ ◄─── 5. REINTEGRATION │
                         │    ADJUSTMENT   │      │ (Bukti Respons  │      (Kepulangan      │
                         │ (Evaluasi Akhir)│      │  Keseharian)    │       Didampingi)     │
                         └─────────────────┘      └─────────────────┘      └────────────────┘
```

## 2. Struktur Standar Rencana Transisi & Pemulihan Santri (RTPS)

Template resmi yang digunakan tim gabungan musyrif, asatidz BK, dan pimpinan pengasuhan:

```text
================================================================================
    RENCANA TRANSISI & PEMULIHAN SANTRI (RTPS) - PESANTREN TUMBUH
================================================================================
Nomor Registrasi  : RTPS-2026-IX-015          Kategori Kasus   : Pemulihan Trauma Emosional
Identitas Santri  : [Nama Santri Terkait]     Kamar Asal/Tujuan: [Abu Ubaidah 1 / Umar 2]
Musyrif Pendamping: [Ust. Abdullah Hadi]      Konselor BK      : [Ustazah Fatimah, S.Psi.]
--------------------------------------------------------------------------------
1. LATAR BELAKANG & KEBUTUHAN (Need & Condition)
   - Kondisi Awal : Mengalami kecemasan sosial berat dan mengisolasi diri pasca-konflik.
   - Hak Perlindungan: Dipastikan bebas dari ancaman fisik dan verbal di lingkungan baru.

2. SASARAN PEMULIHAN (Recovery Goal)
   - Mampu mengikuti shalat jamaah dan makan bersama di ruang makan tanpa serangan panik.
   - Mampu tidur nyenyak minimal 6 jam setiap malam dalam 14 hari berturut-turut.

3. RENCANA TRANSISI & PENDAMPINGAN (Supported Return Plan)
   - Penempatan Baru : Kamar Umar bin Khattab 2 (iklim kamar tenang dan suportif).
   - Sahabat Sebaya  : Santri Senior C (diberikan pembekalan empati untuk menemani).
   - Jadwal Check-in : Konselor BK hadir 2 kali sepekan; musyrif check-in tiap malam.

4. MONITORING RESPONS LAPANGAN (Response Evidence)
   - Pekan 1 : Santri makan bersama dengan tenang; mulai mengobrol dengan sahabat pendamping.
   - Pekan 2 : Mengikuti halaqah Al-Qur'an secara penuh; senyum dan keceriaan kembali tampak.

5. PENINJAUAN & KEPUTUSAN PENYESUAIAN (Review & Decision)
   - Tanggal Review  : 26 Oktober 2026
   - Keputusan       : STEP DOWN SUPPORT (Santri mandiri penuh; pendampingan khusus ditutup).
   - Tindak Lanjut   : Berkas RTPS ditutup dan disimpan dalam arsip rahasia BK pondok.
================================================================================
```

## 3. Matriks Tata Kelola Kerahasiaan Data (*Governance & Privacy Matrix*)

Informasi dalam berkas RTPS memiliki klasifikasi **SANGAT RAHASIA (CONFIDENTIAL)**:

| Pihak Pemangku Kepentingan | Batas Akses Data | Larangan Keras |
| :--- | :--- | :--- |
| **Konselor BK & Dokter Pondok** | Akses penuh terhadap catatan psikologis dan medis. | Dilarang membagikan riwayat terapi santri kepada pihak luar tanpa izin wali. |
| **Musyrif Kamar Baru** | Menerima ringkasan panduan praktis (apa yang perlu didukung, apa pemicu cemas). | Dilarang membaca detail riwayat trauma masa lalu yang tidak relevan dengan tugas harian asrama. |
| **Teman Sekamar / Santri Lain** | **TIDAK ADA AKSES SAMA SEKALI.** | Musyrif dilarang membocorkan alasan pemindahan kamar santri kepada warga kamar. |

## 4. Pagar Batas Epistemik (*Boundary Rules*)

1. **Bukan Status Bebas Masalah Permanen:** Penutupan berkas RTPS bukan jaminan bahwa santri tidak akan pernah menghadapi masa sulit lagi; itu hanya menandai berakhirnya masa pendampingan darurat.
2. **Bukan Bukti Kausalitas Tunggal:** Keberhasilan pemulihan santri adalah buah dari perpaduan doa, ketulusan santri, dukungan teman sebaya, dan taufik Allah SWT semata.
3. **Pemusnahan Berkas Aman:** Setelah santri menyelesaikan masa studi dan lulus dari pesantren, berkas fisik/digital diarsipkan dan dimusnahkan sesuai regulasi perlindungan data pribadi anak.
