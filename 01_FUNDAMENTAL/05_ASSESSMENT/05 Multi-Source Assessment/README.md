## 1. Hakikat dan Tujuan Direktori

Direktori `05 Multi-Source Assessment` mengatur tata kelola triangulasi data perkembangan santri dari berbagai sumber pengamatan (Diri Sendiri, Musyrif/Pendidik, Teman Sebaya, Kinerja Nyata, dan Portofolio Belajar). Tujuannya adalah menangkap potret perkembangan jiwa dan adab santri secara utuh, mencegah kesimpulan sepihak dari satu sudut pandang, serta memastikan integritas dan perlindungan privasi santri tetap terjaga.
