# Perangkat Contoh Format Instrumen Asesmen Siap Pakai
## *Sample Instruments Toolkit for 24-Hour Pesantren Life*

**Status Dokumen:** SPESIFIKASI OPERASIONAL RESMI — Perangkat Asesmen TUMBUH v2.0.0  
**Status Epistemik:** Dirancang Secara Konseptual; Sementara Secara Empiris (*Conceptually Specified; Empirically Provisional*)  
**Kode Konstruk:** INST-Tool-v2.0.0  

> **Kaidah Praktis Pengasuhan Asrama:**  
> **"Teori instrumen yang hebat harus berwujud formulir nyata yang mudah diisi musyrif di sela kesibukan mengasuh santri."**  
> Dokumen ini menyediakan **lima format instrumen lapangan siap pakai** yang dirancang khusus untuk ritme kehidupan 24 jam di pondok pesantren:  
> 1. **Lembar Saku Catatan Anekdotal Musyrif** (Format Pengamat / *Observer Form*)  
> 2. **Lembar Muhasabah Adab Mandiri Santri** (Format Refleksi Batin / *Self-Report Form*)  
> 3. **Format Umpan Balik Ta'awun Sebaya** (Format Apresiasi Kawan / *Peer Feedback Form*)  
> 4. **Lembar Observasi Unjuk Kerja Praktik Ibadah & Khidmah** (Format Unjuk Amal / *Performance Task*)  
> 5. **Panduan Dialog Empat Mata Wali Asuh** (Format Bimbingan Konseling / *Mentor Interview*)  
> Seluruh instrumen mengedepankan pencatatan perilaku nyata, merekam konteks lingkungan dan perancah bantuan, serta menghindari angka skor dingin yang memicu penghakiman.

---

## 1. Instrumen 1: Lembar Saku Pengamatan Anekdotal Musyrif (*Musyrif Pocket Log*)

- **Target Pengguna:** Musyrif Kamar Asrama / Petugas Piket Pengasuhan Malam  
- **Kapasitas Terkait:** CC-01 Regulasi Diri (*Self-Regulation*) & CC-04 Kolaborasi Santri  
- **Format Media:** Buku Saku Saku Ukuran A6 atau Aplikasi Logbook Android Ma'had  

```text
┌────────────────────────────────────────────────────────────────────────┐
│             LEMBAR CATATAN SAKU PENGAMATAN ANEKDOTAL MUSYRIF           │
├────────────────────────────────────────────────────────────────────────┤
│ Nama Santri : Abdullah Hilmi              Kamar : Utsman bin Affan 2   │
│ Tanggal     : Kamis, 22 Oktober 2026      Waktu : 04.05 – 04.30 WIB    │
│ Pengamat    : Ustadz Rahmat Hidayat (Musyrif Kamar)                    │
├────────────────────────────────────────────────────────────────────────┤
│ 1. SITUASI & SUASANA LINGKUNGAN (KONTEKS):                             │
│    Bel bangun shubuh pertama berbunyi pukul 04.00 WIB. Suasana kamar   │
│    dingin dan gelap karena sedang hujan lebat di luar asrama.          │
├────────────────────────────────────────────────────────────────────────┤
│ 2. PERILAKU NYATA TERAMATI (FAKTA LAPANGAN):                           │
│    Abdullah langsung bangun saat bel pertama, melipat selimut dan      │
│    merapikan sprei tempat tidur, menyalakan lampu kamar, lalu bergegas │
│    mengambil handuk untuk berwudhu tanpa perlu dipanggil musyrif.      │
│    Sempat menyapa ramah dan membangunkan seorang kawan sekamarnya.     │
├────────────────────────────────────────────────────────────────────────┤
│ 3. DERAJAT PERANCAH BANTUAN YANG DIBERIKAN (SCAFFOLDING):              │
│    [ ] J1 : Bantuan Penuh Fisik (Dibangunkan langsung oleh musyrif)    │
│    [ ] J2 : Isyarat Sapaan Verbal (Diingatkan lewat sapaan nama santri)│
│    [X] J3 : Mandiri Teruji (Bangun & tertib atas inisiatif kesadaran)  │
│    [ ] J4 : Teladan Penggerak (Membangunkan seluruh kamar dengan adab) │
├────────────────────────────────────────────────────────────────────────┤
│ 4. CATATAN REFLEKSI TARBIYAH:                                          │
│    Konsisten mandiri bangun shubuh selama 10 hari berturut-turut.      │
│    Tidak tampak rasa malas atau menggerutu. Layak diapresiasi saat     │
│    halaqoh kamar ba'da Isya.                                           │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Instrumen 2: Lembar Muhasabah Adab Mandiri Santri (*Self-Reflection Sheet*)

- **Target Pengguna:** Diisi Santri secara Mandiri Sebelum Tidur Malam (21.30 – 21.45 WIB)  
- **Kapasitas Terkait:** CC-01 Regulasi Diri & CC-07 Agensi Spiritual  
- **Prinsip Tarbiyah:** Menumbuhkan kejujuran batin di hadapan Allah SWT (*Nafs Lawwamah*)  

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   LEMBAR MUHASABAH ADAB MALAM HARI SANTRI              │
├────────────────────────────────────────────────────────────────────────┤
│ Nama Santri : Muhammad Faris              Kelas : 8 Madrasah Tsanawiyah│
│ Hari/Tanggal: Kamis, 24 Oktober 2026      Kamar : Ali bin Abi Thalib 1 │
├────────────────────────────────────────────────────────────────────────┤
│ 1. Kebaikan atau amal shalih apa yang paling saya syukuri berhasil     │
│    saya amalkan hari ini dengan tulus ikhlas karena Allah?             │
│    Jawaban Santri:                                                     │
│    "Alhamdulillah hari ini saya bisa menggantikan teman piket menyapu  │
│    teras kamar mandi karena teman saya sedang demam di pos kesehatan." │
├────────────────────────────────────────────────────────────────────────┤
│ 2. Pada situasi apa hari ini saya merasa paling sulit menahan amarah,  │
│    hawa nafsu, atau rasa malas saya?                                   │
│    Jawaban Santri:                                                     │
│    "Saat antrean makan siang sangat panjang dan ada kawan yang         │
│    menyerobot. Saya sempat bersuara keras sebelum akhirnya istighfar." │
├────────────────────────────────────────────────────────────────────────┤
│ 3. Bantuan bimbingan apa dari Ustadz yang paling saya butuhkan besok?  │
│    Jawaban Santri:                                                     │
│    "Saya ingin berkonsultasi cara mengatur waktu hafalan Al-Qur'an agar│
│    tidak mengantuk saat mengikuti pengajian kitab kuning ba'da Isya."  │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. Instrumen 3: Format Umpan Balik Ta'awun Sebaya (*Peer Feedback Protocol*)

- **Target Pengguna:** Diisi sesama rekan santri satu kelompok halaqoh tahfidz / regu piket  
- **Kapasitas Terkait:** CC-03 Komunikasi Santun & CC-04 Kolaborasi Sosial  
- **Prinsip Tarbiyah:** Menguatkan ukhuwah, saling menasihati dalam kebenaran (*tawashau bil-haqq*)  

```text
┌────────────────────────────────────────────────────────────────────────┐
│                     LEMBAR APRESIASI UKHUWAH SEBAYA                    │
├────────────────────────────────────────────────────────────────────────┤
│ Rekan yang Diamati : Farhan Zaki          Kelompok : Halaqah Al-Fatih  │
│ Pengamat Sebaya    : Ahmad Fauzan         Periode  : Pekan Ke-3 Oktober│
├────────────────────────────────────────────────────────────────────────┤
│ 1. Akhlak mulia apa dari kawan ini yang paling menyejukkan hati kami   │
│    di kelompok halaqah sepanjang pekan ini?                            │
│    Jawaban Rekan:                                                      │
│    "Farhan sangat sabar saat menyimak setoran hafalan Al-Qur'an saya   │
│    yang masih terbata-bata, dan tidak pernah menertawakan kesalahan    │
│    makhraj tajwid saya di depan kawan-kawan."                          │
├────────────────────────────────────────────────────────────────────────┤
│ 2. Satu nasihat tulus penuh kasih sayang untuk kebaikan kawan ke depan:│
│    Jawaban Rekan:                                                      │
│    "Semoga Farhan lebih berani berbicara saat musyawarah kamar malam   │
│    hari, agar ide-ide bagusnya bisa didengar oleh semua teman kamar."  │
└────────────────────────────────────────────────────────────────────────┘
```

## 4. Instrumen 4: Lembar Observasi Unjuk Amal Ibadah (*Performance Task Protocol*)

- **Target Pengguna:** Asatidz Penguji Ibadah Amaliah / Pengasuh Asrama  
- **Kapasitas Terkait:** CC-07 Adab Ibadah & CC-03 Komunikasi Santun  
- **Konteks:** Menjadi Badal Imam Shalat Rawatib / Memandu Dzikir Ba'da Shalat  

```text
┌────────────────────────────────────────────────────────────────────────┐
│             LEMBAR OBSERVASI PRAKTIK UNJUK AMAL IBADAH                 │
├────────────────────────────────────────────────────────────────────────┤
│ Nama Santri : Salman Al-Farisi            Tugas : Badal Imam Maghrib   │
│ Tanggal     : Jumat, 25 Oktober 2026      Lokasi: Musholla Asrama 2    │
│ Penilai     : Ustadz Dr. Mukhlis (Dewan Pengasuhan)                    │
├────────────────────────────────────────────────────────────────────────┤
│ ASPEK PENGAMATAN FAKTUAL:                                              │
│ • Adab Merapikan Shaf: Membalikkan badan dengan tenang, mengingatkan   │
│   kelurusan shaf dengan lafaz sunnah yang santun, jelas, dan berwibawa.│
│ • Thuma'ninah & Tartil: Bacaan tartil, makhraj fasih, ruku' dan sujud  │
│   tenang tanpa tergesa-gesa (thuma'ninah terjaga sempurna).            │
│ • Kendali Diri dalam Gangguan: Tetap tenang dan khusyuk saat ada anak  │
│   kecil menangis di shaf belakang, tidak mempercepat shalat mendadak.  │
├────────────────────────────────────────────────────────────────────────┤
│ EVALUASI TINGKAT KEMANDIRIAN AMAL:                                     │
│ [ ] J1 : Perlu Didampingi Fisik (Asatidz berdiri di samping makmum)    │
│ [ ] J2 : Perlu Diingatkan Rukun (Diingatkan urutan doa sebelum shalat) │
│ [X] J3 : Mandiri & Thuma'ninah (Memimpin shalat mandiri dengan tenang) │
│ [ ] J4 : Teladan Khidmah (Membina kekhusyukan seluruh jamaah makmum)   │
├────────────────────────────────────────────────────────────────────────┤
│ UMPAN BALIK TARBIYAH DARI ASATIDZ:                                     │
│ Bacaan sangat menyentuh hati. Disarankan untuk memperpanjang dzikir    │
│ sirr setelah salam sebelum memimpin doa bersama para makmum.           │
└────────────────────────────────────────────────────────────────────────┘
```

## 5. Instrumen 5: Panduan Wawancara Bimbingan Wali Asuh (*Mentor Dialogue Guide*)

- **Target Pengguna:** Wali Asuh Kamar / Guru Bimbingan Konseling (BK) Pesantren  
- **Tujuan:** Menyelami kondisi emosional santri, kesulitan adaptasi, dan cita-cita anak  
- **Prinsip Tarbiyah:** Suasana dialog empat mata yang menenteramkan jiwa (*psychological safety*)  

```text
┌────────────────────────────────────────────────────────────────────────┐
│               PANDUAN DIALOG EMPAT MATA WALI ASUH SANTRI               │
├────────────────────────────────────────────────────────────────────────┤
│ Nama Santri : Rayhan Pratama              Wali Asuh: Ustadz Salman     │
│ Fokus Dialog: Evaluasi Adaptasi Santri Baru (Homesick & Jadwal Kamar)  │
├────────────────────────────────────────────────────────────────────────┤
│ ALUR PERTANYAAN PEMANTIK DIALOGIS:                                     │
│ 1. Pembuka Penuh Kehangatan:                                           │
│    "Bagaimana kabar antum pekan ini, Rayhan? Apa hal yang paling       │
│    membuat antum gembira saat beraktivitas bersama kawan di kamar?"    │
│ 2. Menyelami Kesulitan Tanpa Menghakimi:                               │
│    "Ustadz perhatikan antum tampak lelah dua hari terakhir. Boleh      │
│    ceritakan apa yang sedang antum rasakan di hati dan pikiran antum?" │
│ 3. Menemukan Solusi Bersama:                                           │
│    "Jika rasa rindu pada Ibu datang saat malam hari sebelum tidur,     │
│    hal apa yang biasanya antum lakukan agar hati merasa lebih tenang?" │
│ 4. Kesepakatan Langkah Perbaikan Kecil:                                │
│    "Pekan ini, langkah kecil apa yang ingin kita coba bersama agar     │
│    antum bisa tidur lebih nyenyak dan bangun pagi dengan bugar?"       │
├────────────────────────────────────────────────────────────────────────┤
│ RANGKUMAN REFLEKSI WALI ASUH:                                          │
│ Santri sedang berada pada fase adaptasi rindu keluarga yang wajar.     │
│ Membutuhkan pendampingan empati (J2). Jadwalkan panggilan telepon      │
│ keluarga pada hari Ahad sore sebagai bentuk penguatan afeksi anak.     │
└────────────────────────────────────────────────────────────────────────┘
```

## 6. Petunjuk Praktis bagi Musyrif dalam Menerapkan Toolkit

1. **Cetak Sesuai Kebutuhan Lapangan:**  
   Cetak formulir pengamatan saku dalam ukuran ringkas (A6 atau notes saku) agar praktis dibawa musyrif saat berkeliling asrama dan menyapa santri.
2. **Jaga Kerahasiaan Arsip Pembinaan:**  
   Lembar muhasabah diri santri dan catatan dialog wali asuh wajib disimpan dalam map tertutup di lemari ruang bimbingan, dilarang keras diletakkan terbuka di kamar santri.
3. **Triangulasi Data dalam Musyawarah Bulanan:**  
   Gunakan perpaduan data dari kelima instrumen ini saat sesi musyawarah evaluasi bulanan tim pengasuh ma'had untuk merumuskan langkah bimbingan terbaik bagi setiap santri.
