> ### Intisari untuk Pendidik & Musyrif
> Dokumen ini menyediakan **tiga contoh instrumen lapangan siap pakai** yang disesuaikan dengan ritme kehidupan santri 24 jam:  
> 1. **Lembar Saku Observasi Anekdotal Musyrif Kamar (Format Pengamat)**  
> 2. **Lembar Muhasabah Adab Harian Santri (Format Refleksi Mandiri / Self)**  
> 3. **Format Umpan Balik Rekan Piket Asrama (Format Sebaya / Peer)**  
> Format-format ini dirancang sederhana, mudah diisi di sela-sela kesibukan pengasuhan, dan mengutamakan deskripsi perilaku nyata.

---

## 1. Instrumen 1: Lembar Saku Observasi Anekdotal Musyrif (Musyrif Pocket Log)

- **Sasaran Pengamatan:** Santri Kamar Asrama (Piket Kebersihan & Bangun Shubuh)  
- **Kapasitas Rujukan:** CC-01 Regulasi Diri & CC-04 Kolaborasi  
- **Format Catatan Lapangan:**

```text
┌────────────────────────────────────────────────────────────────────────┐
│             LEMBAR CATATAN SAKU PENGAMATAN ANEKDOTAL MUSYRIF           │
├────────────────────────────────────────────────────────────────────────┤
│ Nama Santri : Abdullah Hilmi              Kamar : Utsman bin Affan 2   │
│ Tanggal     : 22 Oktober 2026             Waktu : 04.05 – 04.30        │
│ Musyrif     : Ustadz Rahmat Hidayat                                    │
├────────────────────────────────────────────────────────────────────────┤
│ SITUASI / KONTEKS:                                                     │
│ Bel bangun Shubuh berbunyi pukul 04.00. Suasana kamar dingin dan gelap │
│ karena hujan rintik-rintik di luar.                                    │
├────────────────────────────────────────────────────────────────────────┤
│ PERILAKU NYATA TERAMATI:                                               │
│ Abdullah langsung mematikan alarm, melipat selimut secara rapi, lalu   │
│ menyalakan lampu kamar. Mengambil handuk dan segera berwudhu tanpa     │
│ perlu dipanggil. Sempat mengingatkan 1 rekannya yang masih tertidur.   │
├────────────────────────────────────────────────────────────────────────┤
│ TINGKAT DUKUNGAN (SCAFFOLDING):                                        │
│ [ ] J1 (Bantuan Penuh)     [ ] J2 (Isyarat Sapaan)                     │
│ [X] J3 (Mandiri Teruji)    [ ] J4 (Penggerak Teladan)                  │
├────────────────────────────────────────────────────────────────────────┤
│ CATATAN REFLEKSI MUSYRIF:                                              │
│ Menunjukkan konsistensi adab bangun pagi yang sangat stabil selama 10  │
│ hari berturut-turut. Tidak tampak rasa malas atau terpaksa.            │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Instrumen 2: Lembar Muhasabah Adab Mandiri Santri (Self-Reflection Sheet)

- **Sasaran:** Santri Mengisi Sebelum Tidur (Pukul 21.30 – 21.45)  
- **Kapasitas Rujukan:** CC-01 Regulasi Diri & CC-07 Agensi  
- **Prinsip:** Kejujuran pribadi di hadapan Allah SWT (*Nafs Lawwamah*)

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   LEMBAR MUHASABAH ADAB MALAM HARI                     │
├────────────────────────────────────────────────────────────────────────┤
│ Nama Santri : Muhammad Faris              Kelas : 8 SMP               │
│ Hari/Tanggal: Kamis, 24 Oktober 2026                                   │
├────────────────────────────────────────────────────────────────────────┤
│ 1. Kebaikan apa yang paling saya syukuri berhasil saya amalkan hari    │
│    ini dengan ikhlas karena Allah?                                     │
│    Jawaban: Alhamdulillah hari ini saya bisa membantu menyapu teras    │
│    kamar mandi saat teman piket saya sedang demam di UKS.              │
├────────────────────────────────────────────────────────────────────────┤
│ 2. Pada situasi apa hari ini saya merasa paling sulit menahan amarah   │
│    atau rasa malas saya?                                               │
│    Jawaban: Saat antre makan siang sangat panjang dan ada kawan yang   │
│    menyerobot. Saya sempat bersuara tinggi sebelum akhirnya istighfar. │
├────────────────────────────────────────────────────────────────────────┤
│ 3. Bentuk bimbingan apa dari Ustadz yang paling saya butuhkan besok?   │
│    Jawaban: Saya ingin berkonsultasi cara membagi waktu hafalan tafsir │
│    agar tidak mengantuk saat pelajaran malam.                          │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. Instrumen 3: Format Umpan Balik Ta'awun Sebaya (Peer Feedback Protocol)

- **Sasaran:** Dinilai sesama rekan satu kelompok kerja bakti / halaqah  
- **Prinsip:** Bahasa santun, mengapresiasi kebaikan, dan saling menasihati dalam kebenaran (*tawashau bil-haqq*)

```text
┌────────────────────────────────────────────────────────────────────────┐
│                     LEMBAR APRESIASI UKHUWAH SEBAYA                    │
├────────────────────────────────────────────────────────────────────────┤
│ Kawan yang diamati : Farhan Zaki          Kelompok : Halaqah Al-Fatih │
│ Periode Pengamatan : Pekan ke-3 Oktober 2026                           │
├────────────────────────────────────────────────────────────────────────┤
│ - Sikap baik apa dari Farhan yang paling menyejukkan hati kelompok     │
│   kami pekan ini?                                                      │
│   "Farhan sangat sabar saat menyimak bacaan hafalan saya yang masih    │
│   terbata-bata, dan tidak pernah menertawakan kesalahan makhraj saya." │
├────────────────────────────────────────────────────────────────────────┤
│ - Satu saran penuh kasih sayang untuk kebaikan Farhan ke depan:        │
│   "Semoga Farhan lebih berani berbicara saat musyawarah kamar agar ide │
│   bagusnya bisa didengar oleh semua teman-teman."                      │
└────────────────────────────────────────────────────────────────────────┘
```
