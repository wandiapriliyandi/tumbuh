# Philosophy V2

Struktur awal turunan Probe II untuk mengorganisasi hasil Philosophy TUMBUH.

> Catatan: struktur ini adalah **draft arsitektural** untuk dilihat dan ditinjau. Ia belum mengklaim bahwa setiap nama file merupakan rumusan literal dari Probe II.

## Alur

`FOUNDATION → HUMAN BEING → KNOWLEDGE → GROWTH → EDUCATION → LEADERSHIP → CHANGE`

Struktur ini dibuat agar pembahasan Philosophy bergerak dari dasar pandangan hidup, manusia, pengetahuan, pertumbuhan, pendidikan, kepemimpinan, lalu perubahan.

Struktur lama `01_PHILOSOPHY` tidak dihapus dan tetap menjadi referensi/legacy.

## Rencana isi

- `01_FOUNDATION` — worldview, values, purpose
- `02_HUMAN_BEING` — human nature, fitrah, dignity, responsibility
- `03_KNOWLEDGE` — sumber pengetahuan, wahyu dan akal, belajar, kebenaran dan pemahaman
- `04_GROWTH` — makna pertumbuhan, tahapan, formation, transformation
- `05_EDUCATION` — tujuan pendidikan, pendidik, lingkungan, relasi pendidikan
- `06_LEADERSHIP` — makna kepemimpinan, pelayanan, amanah/otoritas, perkembangan kepemimpinan
- `07_CHANGE` — hakikat perubahan, perubahan dan pertumbuhan, individual/sistemik, kesinambungan dan transformasi

Struktur ini akan direvisi bila pembacaan penuh Probe II menunjukkan arsitektur yang lebih tepat.
