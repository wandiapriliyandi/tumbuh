# 03_PROGRESSION / 02 Capacity Progression

**Status:** PROPOSED — Wave 3 baseline

## Purpose
Menjelaskan bagaimana suatu kapasitas berkembang dari dukungan tinggi menuju kemandirian dan mastery.

## Progression Logic

```text
Exposure → Understanding → Guided Practice → Independent Performance → Transfer → Mastery
```

Urutan ini adalah model desain awal, bukan hukum universal perkembangan manusia.

## Required Specification
Setiap capacity progression harus memiliki:
- construct yang dirujuk;
- baseline evidence;
- indikator per tingkat;
- kondisi konteks;
- bentuk dukungan;
- evidence of transfer;
- mastery criteria;
- validation status.

## Boundary
Capacity progression tidak boleh disamakan dengan umur, kelas, atau J1–J4. J1–J4 mengatur tingkat dukungan/kemandirian; progression menjelaskan perubahan kapasitas.
