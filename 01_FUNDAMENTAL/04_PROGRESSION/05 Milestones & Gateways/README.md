# 03_PROGRESSION / 05 Milestones & Gateways

**Status:** PROPOSED — Wave 3 baseline

## Purpose
Menetapkan titik perkembangan yang berguna untuk keputusan pembinaan tanpa menjadikannya label tetap pada individu.

## Milestone
Milestone adalah bukti bahwa kriteria perkembangan tertentu telah tercapai pada construct/konteks yang didefinisikan.

## Gateway
Gateway adalah titik keputusan untuk menentukan apakah dukungan, pengalaman belajar, atau tantangan berikutnya layak diberikan.

## Rules
- Gateway berbasis evidence, bukan usia semata.
- Satu milestone tidak otomatis berarti mastery global.
- Kegagalan mencapai gateway bukan hukuman; ia menjadi sinyal untuk review kebutuhan dan dukungan.
