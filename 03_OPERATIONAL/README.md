# Operational

Ruang ini disiapkan untuk produk operasional yang digunakan untuk menjalankan TUMBUH di lembaga.

Produk seperti job description, SOP, tata tertib, program kerja, formulir, template, modul, dan dokumen kerja tidak dianggap sebagai definisi inti TUMBUH. Produk tersebut dapat dibuat, disesuaikan, dan dikembangkan oleh unit/lembaga berdasarkan Fundamental dan Implementation TUMBUH.
