## Batas Peran REFERENCES

`REFERENCES/` adalah perpustakaan dan indeks rujukan yang dikurasi untuk membantu pengembangan TUMBUH. Isinya dapat menjadi bahan bacaan, pembanding, atau sumber awal untuk penyelidikan.

Keberadaan sebuah rujukan di sini **tidak otomatis menjadikannya kebenaran normatif TUMBUH, bukti terverifikasi, atau keputusan desain**. Keputusan dan klaim TUMBUH harus ditelusurkan melalui lapisan yang sesuai, termasuk PROBE, Research, dan terutama registri sumber/evidence ketika suatu klaim digunakan sebagai dasar keputusan.
