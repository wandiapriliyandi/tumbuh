# Functional Dimensions 08 — Problem Solving

## Gampangnya

Functional Dimensions menjelaskan fungsi penting untuk memahami masalah, menentukan jalan penanganan, dan menyesuaikan tindakan berdasarkan kondisi dan hasil.

## Functional Object

> **Gap antara kondisi aktual dan kondisi yang dituju, bersama hambatan, batasan, dan strategi yang relevan untuk menangani gap tersebut.**

## Functional Dimensions

### 1. Problem Representation
Membentuk pemahaman yang cukup tepat tentang kondisi aktual, kondisi yang dituju, hambatan, batasan, dan hubungan antarbagian masalah.

### 2. Strategy Generation / Selection
Menghasilkan atau memilih kemungkinan strategi yang relevan dengan masalah dan kondisi yang tersedia.

### 3. Action Adjustment
Menyesuaikan tindakan atau strategi berdasarkan informasi baru, respons terhadap tindakan, perubahan kondisi, atau hasil yang diperoleh.

## Batas

Dimensions bukan kecerdasan umum, kreativitas saja, pengetahuan saja, satu metode pemecahan masalah, kecepatan bekerja, atau keberhasilan akhir semata. Struktur masalah dapat membuat fungsi-fungsi ini muncul secara berulang dan tidak selalu linear.

## Hubungan Antar-Layer

`CORE CAPACITY → FUNCTIONAL OBJECT → FUNCTIONAL DIMENSIONS → OBSERVABLE MANIFESTATION`
