# Functional Dimensions 05 — Physical Functioning

## Gampangnya

Functional Dimensions menjelaskan fungsi fisik utama yang memungkinkan seseorang menjalankan aktivitas sesuai tuntutan kondisi tertentu.

## Functional Object

> **Physical functioning yang diperlukan untuk menjalankan aktivitas atau memenuhi tuntutan konteks.**

## Functional Dimensions

### 1. Mobility / Movement
Kemampuan melakukan perpindahan atau gerakan tubuh yang relevan dengan aktivitas dan kondisi.

### 2. Manipulation / Control
Kemampuan mengendalikan gerakan atau objek secara fisik sesuai kebutuhan aktivitas.

### 3. Endurance / Function Relative to Demand
Kemampuan mempertahankan fungsi fisik sesuai durasi, intensitas, dan tuntutan aktivitas yang relevan.

## Batas

Dimensions bukan kesehatan secara keseluruhan, penampilan tubuh, kekuatan fisik saja, olahraga tertentu, atau diagnosis medis. Functioning perlu dipahami relatif terhadap aktivitas, lingkungan, accessibility, alat bantu, keselamatan, dan kondisi aktual.
