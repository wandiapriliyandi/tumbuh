# Functional Dimensions

## Purpose

Functional Dimensions menjelaskan fungsi utama yang membentuk masing-masing Core Capacity. Dimensi harus tetap berada pada level fungsi, bukan berubah menjadi indikator, task, atau alat ukur.

## Canonical Mapping

| Core Capacity | Functional Dimensions |
|---|---|
| Self-Regulation | Monitoring; Regulation; Reorientation |
| Critical Thinking | Examination/Analysis; Evaluation; Inference/Judgment; Explanation/Justification |
| Communication | Formulation; Expression/Transmission; Reception; Interpretation |
| Collaboration | Contribution; Coordination; Joint Adjustment |
| Physical Functioning | Mobility/Movement; Manipulation/Control; Endurance/Function relative to Demand |
| Social Understanding | Perspective Interpretation; Relational Interpretation; Social-Context Interpretation |
| Agency | Initiation; Direction; Intentional Action under Conditions |
| Problem Solving | Problem Representation; Strategy Generation/Selection; Action Adjustment |

## Rules

1. Dimension harus menjelaskan **fungsi**, bukan bentuk perilaku tertentu.
2. Dimension tidak sama dengan indicator.
3. Satu manifestasi dapat menjadi evidence bagi lebih dari satu dimension tanpa membuat capacity baru.
4. Dimension tidak boleh berubah menjadi normative trait.
5. Dimension tidak otomatis menunjukkan tahapan perkembangan.
6. Dimension tidak otomatis menjadi subscore assessment.

## Boundary

Functional Dimensions bukan:

- indikator observasi;
- rubric criterion;
- item instrument;
- learning objective;
- task;
- program component;
- atau developmental stage.

## Governance

Perubahan dimensi harus diuji terhadap definisi capacity, functional object, boundaries, relationships, dan traceability. Jika perubahan mengubah struktur internal construct secara material, statusnya harus diperlakukan sebagai construct revision.

## Validation Status

Arsitektur ini berstatus **conceptually specified / empirically provisional**.
