# Functional Dimensions 04 — Collaboration

## Gampangnya

Functional Dimensions menjelaskan fungsi penting dalam membentuk dan menjaga tindakan bersama menuju tujuan bersama.

## Functional Object

> **Joint action dan contribution menuju shared goals.**

## Functional Dimensions

### 1. Contribution
Memberikan tindakan, usaha, pengetahuan, atau sumber daya yang relevan terhadap pekerjaan bersama.

### 2. Coordination
Menyelaraskan peran, waktu, tindakan, dan informasi agar kontribusi individu dapat bekerja sebagai bagian dari tindakan bersama.

### 3. Joint Adjustment
Menyesuaikan tindakan bersama ketika terjadi perubahan kondisi, hambatan, ketidaksesuaian, atau informasi baru.

## Batas

Dimensions bukan pertemanan, jumlah anggota kelompok, kepemimpinan, komunikasi semata, atau hasil kelompok semata. Keberhasilan kelompok tidak otomatis membuktikan kapasitas setiap anggota.
