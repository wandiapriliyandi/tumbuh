# Problem Solving — Functional Object Boundary

## Objek inti
**Gap antara kondisi aktual dan kondisi yang dituju, bersama hambatan, batasan, dan strategi yang relevan untuk menangani gap tersebut.**

## Termasuk
- perbedaan antara kondisi aktual dan kondisi yang dituju;
- hambatan atau batasan yang relevan;
- kemungkinan strategi untuk menangani gap;
- penyesuaian tindakan berdasarkan informasi dan hasil.

## Bukan objek
- kecerdasan umum;
- kreativitas saja;
- pengetahuan saja;
- satu metode pemecahan masalah;
- kecepatan menyelesaikan tugas;
- keberhasilan akhir semata.

## Uji batas
Problem Solving bekerja terhadap **gap dan kondisi masalah**, bukan terhadap satu jawaban tertentu. Outcome dapat dipengaruhi resources, tools, waktu, support, dan kondisi eksternal.

## Hubungan
`Problem Solving → Gap / Obstacles / Strategies → Problem Representation / Strategy Generation-Selection / Action Adjustment`
