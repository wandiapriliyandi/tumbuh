# Agency — Functional Object Boundary

## Objek inti
**Intentional action under real conditions.**

## Termasuk
- memulai tindakan yang disengaja;
- mengarahkan tindakan pada maksud atau tujuan;
- menggunakan ruang bertindak yang benar-benar tersedia;
- bertindak sambil menghadapi batasan nyata.

## Bukan objek
- keinginan saja;
- motivasi saja;
- kebebasan tanpa batas;
- keberhasilan outcome;
- kepemimpinan;
- kemandirian absolut.

## Uji batas
Bedakan `INTENTION → ACTION → OUTCOME`. Agency terutama menyangkut **tindakan yang sengaja dimulai dan diarahkan**, bukan jaminan bahwa outcome akan tercapai.

## Hubungan
`Agency → Intentional Action → Initiation / Direction / Intentional Action under Conditions`

**Status:** Conceptually specified / empirically provisional.
