# Collaboration — Functional Object Boundary

## Objek inti
**Joint action dan contribution menuju shared goals.**

## Termasuk
- tindakan individual sebagai bagian dari tindakan bersama;
- kontribusi terhadap tujuan bersama;
- penyelarasan tindakan dan peran;
- penyesuaian bersama ketika kondisi berubah.

## Bukan objek
- jumlah anggota kelompok;
- pertemanan;
- komunikasi saja;
- kepemimpinan saja;
- outcome kelompok semata.

## Uji batas
Objek Collaboration adalah **tindakan bersama**, bukan kelompok sebagai benda dan bukan keberhasilan akhir kelompok.

## Hubungan
`Collaboration → Joint Action → Contribution / Coordination / Joint Adjustment`

**Status:** Conceptually specified / empirically provisional.
