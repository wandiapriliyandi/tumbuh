# Architectural Trace

## Gampangnya

Architectural Trace memastikan bahwa setiap construct dalam Core Capacity Architecture dapat ditelusuri ke arah normatif di atasnya dan ke artefak pengembangan di bawahnya.

## Canonical Chain

```text
Worldview / Normative Direction
        ↓
Graduate Profile
        ↓
Core Capacity
        ↓
Functional Object
        ↓
Functional Dimensions
        ↓
Observable Manifestations
        ↓
Evidence
        ↓
Progression
        ↓
Assessment
        ↓
Intervention
        ↓
Implementation
        ↓
Evidence & Research
```

Chain ini adalah **mekanisme traceability**, bukan klaim bahwa setiap layer merupakan penyebab layer berikutnya.

## Apa yang Harus Bisa Ditelusuri?

Setiap Core Capacity minimal harus dapat menjawab:

1. Berasal dari arah normatif mana?
2. Apa functional object-nya?
3. Apa functional dimensions-nya?
4. Bagaimana functioning dapat muncul secara observable?
5. Evidence apa yang dapat digunakan?
6. Bagaimana ia diterjemahkan ke progression?
7. Bagaimana ia diamati melalui assessment?
8. Bagaimana hasil assessment dapat menginformasikan intervention?

## Traceability Matrix

| Layer | Pertanyaan |
|---|---|
| Graduate Profile | Manusia seperti apa yang dituju? |
| Core Capacity | Kapasitas apa yang perlu berkembang? |
| Functional Object | Kapasitas itu bekerja terhadap apa? |
| Functional Dimensions | Fungsi penting apa yang membentuknya? |
| Manifestation | Bagaimana fungsi dapat tampak dalam konteks? |
| Evidence | Apa dasar untuk menyimpulkan functioning? |
| Progression | Bagaimana perubahan kapasitas direpresentasikan? |
| Assessment | Bagaimana functioning dinilai secara bertanggung jawab? |
| Intervention | Respons apa yang relevan? |

## Boundary

`TRACEABLE ≠ VALIDATED ≠ CAUSAL ≠ EFFECTIVE`

Traceability menunjukkan keterhubungan arsitektural. Ia tidak dengan sendirinya membuktikan validitas construct, hubungan sebab-akibat, atau efektivitas intervensi.

## Status

**Conceptually specified / empirically provisional.**
