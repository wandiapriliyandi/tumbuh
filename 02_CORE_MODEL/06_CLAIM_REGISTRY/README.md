# Claim Registry

Registry kanonik untuk klaim TUMBUH, tipe klaim, status epistemik, evidence, keterbatasan, dan dampak keputusan.

## Claim Types
- NORMATIVE
- DEFINITIONAL
- DESIGN
- EMPIRICAL
- CAUSAL
- PREDICTIVE
- IMPLEMENTATION
- OUTCOME
- EFFECTIVENESS
- SAFETY
- HYPOTHESIS
- SIMULATION

## Boundary
Registry ini adalah epistemic governance, bukan Core Model substantif.
