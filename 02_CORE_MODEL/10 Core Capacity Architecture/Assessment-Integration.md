# Core Capacity Assessment Integration

## Status

**DESIGNED — v2.0.0**

Core Capacity Assessment terhubung dengan Progression dan Assessment melalui intended inference dan evidence, tanpa mengubah profile menjadi identity atau surveillance.

## Canonical Flow

```text
Core Capacity
→ Progression
→ Evidence
→ Scoped Judgment
→ Decision
→ Support / Intervention
→ Reassessment
```

## Multi-Source Principle

Tidak ada source yang otomatis menjadi gold standard untuk semua capacity. Source dipilih berdasarkan intended inference dan konteks.

## Quality Principle

Assessment quality harus mempertahankan:

- construct representation;
- contextual relevance;
- evidence sufficiency;
- uncertainty;
- fairness;
- proportionality terhadap decision consequence.

## Monitoring Boundary

Monitoring harus memiliki purpose limitation dan data minimization.

> **Monitoring ≠ Surveillance.**

## Reporting Boundary

Report harus menyampaikan evidence scope, context, support condition, uncertainty, limitations, functioning pattern, dan decision implication secara proporsional.

> **Assessment Profile ≠ Person.**

## Automation / AI

Automated output adalah decision support, bukan truth. Human review, construct alignment, dan uncertainty tetap diperlukan.

## High-Stakes Decisions

Semakin tinggi consequence keputusan, semakin kuat kebutuhan evidence diversity, review, documentation, voice/correction, dan reversibility.

## Muwashofat

10 Muwashofat tetap normative/graduate orientation dan tidak menjadi covert capacity score.
