# System Flow — Alur Sistem TUMBUH

## Gampangnya

System Flow menjelaskan bagaimana bagian-bagian TUMBUH tersambung sebagai satu sistem. Ini adalah **alur ketergantungan konseptual**, bukan urutan bahwa manusia selalu tumbuh secara linear.

## Canonical Flow

```text
WORLDVIEW / NORMATIVE DIRECTION
              ↓
       GRADUATE PROFILE
              ↓
          CORE MODEL
              ↓
        PROGRESSION
              ↓
         ASSESSMENT
              ↓
        INTERVENTION
              ↓
       IMPLEMENTATION
              ↓
     OBSERVED OUTCOMES
              ↓
     EVIDENCE & RESEARCH
              ↓
   CONTINUOUS IMPROVEMENT
              ↺
```

## Di Dalam Core Model

```text
Growth Ecology
      ↓
Growth Mechanism
      ↓
Core Capacity Architecture
```

- Growth Ecology menjelaskan konteks dan relasi pertumbuhan.
- Growth Mechanism menjelaskan bagaimana perubahan kapasitas dapat berlangsung.
- Core Capacity Architecture menjelaskan apa yang berkembang dan bagaimana construct direpresentasikan.

## Aturan Membaca

Flow menjawab **bagaimana sistem terhubung**, bukan bagaimana setiap individu pasti berkembang.

Tidak semua keputusan harus bergerak satu arah. Evidence dapat memicu review terhadap progression, assessment, intervention, implementation, atau bahkan construct ketika governance dan evidence membenarkannya.

## Boundary

System Flow bukan causal model. Panah berarti hubungan atau dependency arsitektural, bukan otomatis "A menyebabkan B".

## Status

**Conceptually specified / empirically provisional.**
