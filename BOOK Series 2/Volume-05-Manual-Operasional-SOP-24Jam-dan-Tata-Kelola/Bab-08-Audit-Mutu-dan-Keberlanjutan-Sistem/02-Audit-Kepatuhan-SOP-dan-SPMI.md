# SUB-BAB 8.2: AUDIT KEPATUHAN SOP PENGASUHAN & PENJAMINAN MUTU INTERNAL (SPMI)

---

## 1. Audit Berkala Lembaga Penjamin Mutu Pesantren

Ekosistem TUMBUH mendirikan **Lembaga Penjaminan Mutu Internal (LPMI / SPMI Pesantren)** yang independen dari struktur operasional harian. LPMI bertugas melakukan audit kepatuhan (*compliance audit*) setiap bulan: [^1]

```
               DAFTAR AUDIT KEPATUHAN BULANAN SPMI PESANTREN
  
  ┌──────────────────────────┬───────────────────────┬───────────────────────┐
  │ ASPEK AUDIT              │ TARGET STANDAR MUTU   │ METODE PEMERIKSAAN    │
  ├──────────────────────────┼───────────────────────┼───────────────────────┤
  │ 1. Zero Corporal Punish. │ 100% Bebas Kekerasan  │ Wawancara acak santri │
  │ 2. Rasio Apresiasi       │ >= 4:1 di Logbook     │ Audit data digital    │
  │ 3. Jam Kerja Musyrif     │ Maksimal 8 Jam/Hari   │ Cek presensi shift    │
  │ 4. Audit Kamar 5S        │ >= 95% Kamar Layak    │ Inspeksi fisik acak   │
  │ 5. Respon Perbaikan      │ < 24 Jam Sarpras      │ Cek tiket helpdesk    │
  │ 6. Sanitasi & Air        │ Bebas Scabies         │ Laporan Poskestren    │
  └──────────────────────────┴───────────────────────┴───────────────────────┘
```

---

## 2. Tindakan Korektif & Siklus Peningkatan Mutu

Temuan audit LPMI diserahkan langsung kepada Pimpinan Pondok dan Kepala Madrasah. Staf atau unit kerja yang belum memenuhi standar tidak dihukum, melainkan diberikan **Rencana Tindakan Korektif (*Corrective Action Plan*)** dan pendampingan pelatihan ulang.
