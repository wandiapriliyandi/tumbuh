## 1. Panduan Operasional Per Menit Tiap Shift Kerja

Setiap musyrif yang bertugas dibekali lembar panduan kerja (*SOP Checklist*) agar tidak ada tugas yang terlewat:

```
               CHECKLIST OPERASIONAL MUSYRIF PER SHIFT KERJA
  
  ┌───────────────┬──────────────────────────────────────────────────────────┐
  │ SHIFT KERJA   │ CHECKLIST TUGAS UTAMA (SOP MUTLAK)                       │
  ├───────────────┼──────────────────────────────────────────────────────────┤
  │ SHIFT 1       │ • 03:30 : Bangunkan santri santun & nyalakan lampu koridor│
  │ (Fajar/Pagi)  │ • 04:15 : Kawal shaf masjid Subuh & zikir ma'tsurat      │
  │ 03:30 - 08:00 │ • 05:30 : Dampingi halaqah tahfidz Subuh                 │
  │               │ • 06:30 : Inspeksi cepat kamar 5S & sarapan bersama      │
  │               │ • 07:00 : Pimpin Daily Handover ke Koordinator Madrasah  │
  ├───────────────┼──────────────────────────────────────────────────────────┤
  │ SHIFT 2       │ • 11:30 : Sambut kepulangan KBM sesi 1 di masjid         │
  │ (Dzuhur)      │ • 12:00 : Kawal sholat Dzuhur & ketertiban makan siang   │
  │ 11:30 - 14:00 │ • 12:30 : Pastikan lampu kamar padam untuk Qailulah      │
  │               │ • 13:15 : Bangunkan santri untuk KBM siang madrasah      │
  ├───────────────┼──────────────────────────────────────────────────────────┤
  │ SHIFT 3       │ • 15:30 : Terima Daily Handover sore dari Madrasah       │
  │ (Sore)        │ • 16:00 : Kawal sholat Ashar & aktivitas olahraga sore   │
  │ 15:30 - 18:30 │ • 17:15 : Kawal antrean mandi sore tertib & bersih       │
  │               │ • 18:00 : Pastikan santri telah di masjid sebelum Maghrib│
  ├───────────────┼──────────────────────────────────────────────────────────┤
  │ SHIFT 4       │ • 18:30 : Dampingi kajian kitab ba'da Maghrib & Isya'    │
  │ (Malam/Tidur) │ • 19:45 : Kawal makan malam bersama & mudzakarah kamar   │
  │ 18:30 - 03:30 │ • 21:15 : Pimpin muhasabah kamar & doa tidur             │
  │               │ • 21:45 : Padamkan lampu asrama & patroli hening malam   │
  │               │ • 23:00 - 03:30 : Istirahat jaga di ruang pos musyrif    │
  └───────────────┴──────────────────────────────────────────────────────────┘
```

Dengan standarisasi checklist ini, setiap musyrif memiliki kepastian alur kerja yang jernih, profesional, dan bebas dari kebingungan lapangan.
