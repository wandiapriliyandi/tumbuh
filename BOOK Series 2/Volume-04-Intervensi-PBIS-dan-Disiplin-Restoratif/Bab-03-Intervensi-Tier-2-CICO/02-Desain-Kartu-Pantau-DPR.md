# SUB-BAB 3.2: DESAIN KARTU PANTAU PERILAKU HARIAN (*DAILY PROGRESS REPORT - DPR*)

---

## 1. Instrumen Sederhana Berbasis Bukti Nyata

**Kartu Pantau Perilaku Harian (*Daily Progress Report - DPR*)** adalah lembar instrumen berukuran saku (atau format digital pada tablet santri) yang dibawa oleh peserta CICO sepanjang hari untuk memantau 3 target ekspektasi perilaku utama: [^1]

```
               KARTU PERKEMBANGAN HARIAN SANTRI (DPR TIER 2)
  Nama Santri: Fatih Ahmad        Kamar: Ibnu Khaldun 2        Tanggal: 27/08/2026
  Musyrif CICO: Ustadz Salman     Target Harian: >= 80% Poin
  
  [Sistem Skoring Tiap Sesi: 2 = Hebat/Mandiri, 1 = Cukup/Diingatkan, 0 = Perlu Bimbingan]
  
  ┌─────────────────────────┬──────────────┬──────────────┬──────────────┬────────┐
  │ WAKTU / SESI AKTIVITAS   │ 1. TAQWALLAH │ 2. IKRAM     │ 3. MAS'ULIYAH│ PARAF  │
  ├─────────────────────────┼──────────────┼──────────────┼──────────────┼────────┤
  │ Fajar & Asrama Pagi     │    [ 2 ]     │    [ 2 ]     │    [ 2 ]     │  Ust.S │
  │ KBM Madrasah Pagi 1-2   │    [ 2 ]     │    [ 2 ]     │    [ 1 ]     │  Ust.H │
  │ KBM Madrasah Pagi 3-4   │    [ 2 ]     │    [ 2 ]     │    [ 2 ]     │  Ust.R │
  │ Dzuhur & Makan Siang    │    [ 2 ]     │    [ 2 ]     │    [ 2 ]     │  Ust.S │
  │ KBM Madrasah Siang 5-6  │    [ 2 ]     │    [ 1 ]     │    [ 2 ]     │  Ust.K │
  │ Sore: Olahraga & Mandi  │    [ 2 ]     │    [ 2 ]     │    [ 2 ]     │  Ust.M │
  │ Maghrib & Isya' Jamaah  │    [ 2 ]     │    [ 2 ]     │    [ 2 ]     │  Ust.S │
  │ Mudzakarah Malam        │    [ 2 ]     │    [ 2 ]     │    [ 2 ]     │  Ust.S │
  └─────────────────────────┴──────────────┴──────────────┴──────────────┴────────┘
  TOTAL POIN DIPEROLEH: 45 dari Total Maksimal 48 Poin (93.7%) — [TARGET TERCAPAI!]
```

---

## 2. Aturan Pemberian Umpan Balik oleh Guru dan Musyrif

1. **Umpan Balik Cepat & Konstruktif (<30 Detik)**: Guru memberikan paraf dan skor di akhir jam pelajaran sambil memberikan dorongan verbal singkat: *"Terima kasih Fatih, antum sangat fokus dalam halaqah nahwu tadi."*
2. **Tanpa Debat atau Kemarahan di Depan Kelas**: Jika ada target yang belum terpenuhi (skor 1 atau 0), guru menjelaskannya secara tenang dan objektif tanpa membentak atau mempermalukan santri di depan teman-temannya.
